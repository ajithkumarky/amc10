> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a deployable Next.js 15 project on Cloudflare Pages with the Cyber Anime / Persona theme system, a styled home page with topic tiles, and the design-system primitives that all later plans will reuse.

**Architecture:** Next.js 15 App Router + React 19 + TypeScript + Tailwind CSS v3 + Vitest/RTL for unit tests + `@cloudflare/next-on-pages` adapter for Cloudflare Pages deployment. No auth, no database, no MDX, no content — those land in Plans 2–5. Topic metadata is hardcoded in `lib/topics.ts` and gets wired to real content in Plan 2.

**Tech Stack:** Next.js 15, React 19, TypeScript 5, Tailwind 3.4, Vitest, @testing-library/react, @cloudflare/next-on-pages, wrangler.

**Parallelism:** Phases A → B → C → D are serial. Within **Phase B (Tasks 4–10)**, all seven component/library tasks are independent and SHOULD be dispatched to parallel subagents.

```typescript
import Link from 'next/link';
import { type ReactNode } from 'react';
import { cn } from '@/lib/cn';

type Variant = 'filled' | 'ghost';

const base =
  'inline-flex items-center gap-2 rounded-[2px] px-3 py-1 text-[11px] font-bold uppercase tracking-widest';

const variants: Record<Variant, string> = {
  filled: 'bg-cyber-chip text-white',
  ghost: 'border border-cyber-cyan bg-transparent text-cyber-cyan',
};

interface CommonProps {
  variant?: Variant;
  className?: string;
  children: ReactNode;
}

interface AnchorProps extends CommonProps {
  href: string;
}

interface SpanProps extends CommonProps {
  href?: undefined;
}

export type ChipProps = AnchorProps | SpanProps;

export function Chip({ variant = 'filled', className, href, children }: ChipProps) {
  const classes = cn(base, variants[variant], className);
  if (href) {
    return (
      <Link href={href} className={classes}>
        {children}
      </Link>
    );
  }
  return <span className={classes}>{children}</span>;
}
```
