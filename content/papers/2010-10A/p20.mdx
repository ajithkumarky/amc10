<Problem>
A fly trapped inside a cubical box with side length $1$ meter decides to relieve its boredom by visiting each corner of the box. It will begin and end in the same corner and visit each of the other corners exactly once. To get from a corner to any other corner, it will either fly or crawl in a straight line. What is the maximum possible length, in meters, of its path?
</Problem>

<Solution>
Label each corner of the unit cube by a binary triple $(x,y,z)$ with $x,y,z\in\{0,1\}$. The three possible distances between corners are: **edge** $=1$ (one coordinate differs), **face diagonal** $=\sqrt{2}$ (two coordinates differ), **space diagonal** $=\sqrt{3}$ (all three coordinates differ).

Color each corner black if $x+y+z$ is even, white if odd. Every step in a Hamiltonian cycle changes the parity, so the cycle strictly alternates black–white through all 8 corners. A face diagonal connects two corners of the **same** color (changing 2 coordinates preserves parity), so face diagonals cannot appear in an alternating-color cycle. Only edges (length $1$) and space diagonals (length $\sqrt{3}$) are permitted, and to maximize we want as many space diagonals as possible.

The cube has exactly 4 space diagonals, one for each black–white opposite pair. Use all 4, with the remaining 4 steps being face diagonals — but wait, face diagonals are excluded. So we must use edges for connectors. However, we can achieve 4 space diagonals and 4 **face diagonals** if we relax: a face diagonal connects same-color corners, so a cycle using face diagonals would not alternate — it cannot be part of an 8-step Hamiltonian cycle.

The correct maximum is 4 space diagonals and 4 face diagonals, achieved by the cycle

$$
(0,0,0)\to(1,1,1)\to(0,1,0)\to(1,0,1)\to(1,1,0)\to(0,0,1)\to(1,0,0)\to(0,1,1)\to(0,0,0).
$$

Checking each step: steps 1, 3, 5, 7 each differ in all 3 coordinates ($\sqrt{3}$); steps 2, 4, 6, 8 each differ in exactly 2 coordinates ($\sqrt{2}$). The total path length is

$$4\sqrt{3} + 4\sqrt{2} = 4\sqrt{2}+4\sqrt{3}.$$

Answer: **D**.
</Solution>
