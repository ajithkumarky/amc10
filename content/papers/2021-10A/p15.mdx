<Problem>
Values for $A, B, C,$ and $D$ are to be selected from $\{1, 2, 3, 4, 5, 6\}$ without replacement (i.e. no two letters have the same value). How many ways are there to make such choices so that the two curves $y = Ax^2 + B$ and $y = Cx^2 + D$ intersect? (The order in which the curves are listed does not matter; for example, the choices $A = 3, B = 2, C = 4, D = 1$ is considered the same as $A = 4, B = 1, C = 3, D = 2.$)
</Problem>

<Solution>
The parabolas $y = Ax^2 + B$ and $y = Cx^2 + D$ intersect when $(A-C)x^2 = D-B$ has a real solution. Since all four values are distinct, $A \neq C$, so this requires $x^2 = \dfrac{D-B}{A-C} \geq 0$, i.e., $D-B$ and $A-C$ must have the same sign.

**Total unordered assignments.** Choose 4 distinct values from $\{1,\ldots,6\}$: $\binom{6}{4} = 15$ subsets. Each subset admits $4! = 24$ ordered assignments to $(A,B,C,D)$; dividing by $2$ for the unordered pair of curves gives $12$ unordered assignments per subset, for $15 \times 12 = 180$ total.

**Symmetry argument.** For a fixed 4-element subset, swapping $B \leftrightarrow D$ (while keeping $A$ and $C$) maps every intersecting assignment to a non-intersecting one and vice versa (since $\frac{D-B}{A-C} > 0 \iff \frac{B-D}{A-C} < 0$). This involution pairs intersecting and non-intersecting assignments, so exactly half of the $12$ assignments per subset produce intersection.

The number of valid choices is $15 \times 6 = 90$.

Answer: **C**.
</Solution>
