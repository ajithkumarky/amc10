<Problem>
How many integer values of $x$ satisfy $|x| < 3\pi$?
</Problem>

<Solution>
We need $|x| < 3\pi$. Since $\pi \approx 3.14159$, we have $3\pi \approx 9.4248$.

So we need $|x| < 9.4248$, which means $-9.4248 < x < 9.4248$.

The integers in this range are $-9, -8, -7, \ldots, 7, 8, 9$. That is all integers from $-9$ to $9$, giving $9 + 1 + 9 = 19$ values.

Answer: **D**.
</Solution>
