<Problem>
Bernardo and Silvia play the following game. An integer between 0 and 999, inclusive, is selected and given to Bernardo. Whenever Bernardo receives a number, he doubles it and passes the result to Silvia. Whenever Silvia receives a number, she adds 50 to it and passes the result to Bernardo. The winner is the last person who produces a number less than 1000. Let $N$ be the smallest initial number that results in a win for Bernardo. What is the sum of the digits of $N$?
</Problem>

<Solution>
Starting from $N$, the sequence of outputs alternates Bernardo (doubles) then Silvia (adds 50). The value after Bernardo's $k$-th turn and Silvia's $k$-th turn can be written explicitly:

- Bernardo's $k$-th output: $2^k N + 50(2^{k-1} + 2^{k-2} + \cdots + 1) \cdot 2 - 50 = 2^k N + 50(2^k - 2)$

Working out the first few values gives a cleaner pattern. Bernardo wins when he produces the last number below 1000 and then Silvia's next output meets or exceeds 1000. Silvia's output after Bernardo's $k$-th turn is Bernardo's $k$-th output plus 50, so the condition is:

$$B_k < 1000 \le B_k + 50 \implies 950 \le B_k \le 999,$$

where $B_k$ is Bernardo's $k$-th output. Tracking $B_k$ explicitly:

| $k$ | $B_k$ | Win condition on $N$ |
|-----|--------|----------------------|
| 1 | $2N$ | $475 \le N \le 499$ |
| 2 | $4N+100$ | $213 \le N \le 224$ |
| 3 | $8N+300$ | $82 \le N \le 87$ |
| 4 | $16N+700$ | $16 \le N \le 18$ |
| 5 | $32N+1500$ | impossible ($1500>999$) |

In each range, one must also verify that all earlier outputs stay below 1000, which holds automatically for those small values of $N$. The smallest winning $N$ is therefore $N = 16$.

Verification: $16 \to 32 \to 82 \to 164 \to 214 \to 428 \to 478 \to 956 \to 1006$. Bernardo produces 956 (the last value below 1000), then Silvia produces 1006, so Bernardo wins. The sum of digits of $16$ is $1+6=7$.

Answer: **A**.
</Solution>
