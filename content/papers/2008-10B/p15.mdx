<Problem>
How many right triangles have integer leg lengths $a$ and $b$ and a hypotenuse of length $b + 1$, where $b < 100$?
</Problem>

<Solution>
We need $a^2 + b^2 = (b+1)^2 = b^2 + 2b + 1$, so $a^2 = 2b + 1$.

This means $a^2$ must be odd, so $a$ is odd. Write $a = 2m+1$ for non-negative integer $m$:
$$a^2 = (2m+1)^2 = 4m^2 + 4m + 1 = 2b + 1 \implies b = 2m^2 + 2m = 2m(m+1).$$

We also need $a \geq 1$ (i.e., $m \geq 0$, but $a = 1$ gives $b = 0$ which isn't a valid triangle leg), and $b < 100$.

For $m = 1$: $a = 3$, $b = 4$. Valid.
For $m = 2$: $a = 5$, $b = 12$. Valid.
For $m = 3$: $a = 7$, $b = 24$. Valid.
For $m = 4$: $a = 9$, $b = 40$. Valid.
For $m = 5$: $a = 11$, $b = 60$. Valid.
For $m = 6$: $a = 13$, $b = 84$. Valid.
For $m = 7$: $a = 15$, $b = 112 > 99$. Stop.

There are $6$ valid triangles.

Answer: **A**.
</Solution>
