<Problem>
If $a + 1 = b + 2 = c + 3 = d + 4 = a + b + c + d + 5$, then $a + b + c + d$ is
</Problem>

<Solution>
Let the common value be $k$. Then:
$$a = k-1, \quad b = k-2, \quad c = k-3, \quad d = k-4.$$

Also $a + b + c + d + 5 = k$, so:
$$a + b + c + d = k - 5.$$

But from the expressions above:
$$a + b + c + d = (k-1)+(k-2)+(k-3)+(k-4) = 4k - 10.$$

Setting equal: $4k - 10 = k - 5 \implies 3k = 5 \implies k = \dfrac{5}{3}$.

Therefore $a + b + c + d = k - 5 = \dfrac{5}{3} - 5 = -\dfrac{10}{3}$.

Answer: **B**.
</Solution>
