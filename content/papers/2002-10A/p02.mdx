<Problem>
For the nonzero numbers $a$, $b$, $c$, define $(a, b, c) = \dfrac{a}{b} + \dfrac{b}{c} + \dfrac{c}{a}$. Find $(2, 12, 9)$.
</Problem>

<Solution>
Substitute $a = 2$, $b = 12$, $c = 9$:

$$\frac{2}{12} + \frac{12}{9} + \frac{9}{2} = \frac{1}{6} + \frac{4}{3} + \frac{9}{2}.$$

Using a common denominator of $6$:

$$\frac{1}{6} + \frac{8}{6} + \frac{27}{6} = \frac{36}{6} = 6.$$

Answer: **C**.
</Solution>
