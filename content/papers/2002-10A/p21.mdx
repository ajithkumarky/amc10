<Problem>
The mean, median, unique mode, and range of a collection of eight integers are all equal to $8$. The largest integer that can be an element of this collection is
</Problem>

<Solution>
Write the eight integers in non-decreasing order as $a_1 \le a_2 \le \cdots \le a_8$.

**From the conditions:**
- Mean $= 8$: $a_1 + \cdots + a_8 = 64$.
- Median $= 8$: $a_4 + a_5 = 16$.
- Range $= 8$: $a_8 - a_1 = 8$, i.e., $a_1 = a_8 - 8$.
- Unique mode $= 8$: the value $8$ appears more often than any other value.

To maximize $a_8 = M$, we must have $a_1 = M - 8$. To keep the mode uniquely $8$, the value $M - 8$ can appear at most as often as $8$ minus one; the most efficient approach is to have $8$ appear exactly $3$ times and all other values appear exactly once.

**Try $8$ appearing $3$ times**, say $a_4 = a_5 = a_6 = 8$ (so the median $= (a_4+a_5)/2 = 8$ holds). Then:
$$a_1 + a_2 + a_3 + 8 + 8 + 8 + a_7 + a_8 = 64 \implies a_1 + a_2 + a_3 + a_7 = 40 - M.$$

Set $a_1 = M - 8$, $a_7 = M - 1$ (just below $M$ and above $8$, at minimum $a_7 = 9$ for small $M$). To minimize $a_1 + a_2 + a_3 + a_7$ and thus allow maximum $M$, pick $a_7 = 9$ (smallest allowed value $> 8$).

Then $a_1 + a_2 + a_3 = 31 - M$.

We need $a_1 < a_2 < a_3 < 8$ (all distinct, each value appearing once), so $a_3 \le 7$. With $a_1 = M - 8$:

$$a_2 + a_3 = 31 - M - (M - 8) = 39 - 2M.$$

For $M = 13$: $a_1 = 5$, $a_2 + a_3 = 13$, with $5 < a_2 < a_3 \le 7$. Taking $a_2 = 6$, $a_3 = 7$ gives sum $13$. 

**Verify $M = 13$:** The collection is $5, 6, 7, 8, 8, 8, 9, 13$.
- Sum: $5+6+7+24+9+13 = 64$. Mean $= 8$. $\checkmark$
- Median: $(a_4+a_5)/2 = (8+8)/2 = 8$. $\checkmark$
- Mode: $8$ appears $3$ times; all others appear once. Unique mode $= 8$. $\checkmark$
- Range: $13 - 5 = 8$. $\checkmark$

For $M = 14$: $a_1 = 6$, $a_2 + a_3 = 11$ with $6 < a_2 < a_3 \le 7$. The only integer strictly between $6$ and $8$ is $7$, so we cannot find two distinct values. No valid collection exists with $M = 14$.

The largest possible element is $13$.

Answer: **D**.
</Solution>
