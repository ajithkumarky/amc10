<Problem>
Define the operation $\star$ by $a \star b = (a+b)b.$ What is $(3 \star 5) - (5 \star 3)?$
</Problem>

<Solution>
Compute each value using the definition $a \star b = (a+b)b$:

$$3 \star 5 = (3+5) \cdot 5 = 8 \cdot 5 = 40.$$
$$5 \star 3 = (5+3) \cdot 3 = 8 \cdot 3 = 24.$$

Therefore $(3 \star 5) - (5 \star 3) = 40 - 24 = 16.$

Answer: **E**.
</Solution>
