<Problem>
How many pairs of positive integers $(a,b)$ are there such that $a$ and $b$ have no common factors greater than $1$ and
$$\frac{a}{b} + \frac{14b}{9a}$$
is an integer?
</Problem>

<Solution>
Let $\dfrac{a}{b} + \dfrac{14b}{9a} = k$ for some positive integer $k$. Multiplying through by $9ab$:
$$9a^2 + 14b^2 = 9abk.$$

Since $\gcd(a,b) = 1$, we analyze divisibility. From $9a^2 + 14b^2 = 9abk$, we get $9a^2 \equiv -14b^2 \pmod{b}$, but since $b \mid 9a^2$ (because $9a^2 = 9abk - 14b^2$ and $b$ divides $9abk$ and $14b^2$)… more cleanly:

$$9a^2 = b(9ak - 14b) \implies b \mid 9a^2.$$

Since $\gcd(a,b) = 1$, we have $\gcd(b, a^2) = 1$, so $b \mid 9$. Hence $b \in \{1, 3, 9\}$.

Similarly, $14b^2 = a(9bk - 9a)$, so $a \mid 14b^2$. Since $\gcd(a,b)=1$, $a \mid 14$. Hence $a \in \{1, 2, 7, 14\}$.

Now check each pair $(a,b)$ with $b \in \{1,3,9\}$, $a \in \{1,2,7,14\}$, $\gcd(a,b)=1$, and $\dfrac{a}{b}+\dfrac{14b}{9a} \in \mathbb{Z}$:

The expression equals $\dfrac{9a^2 + 14b^2}{9ab}$. For this to be an integer, $9ab \mid 9a^2 + 14b^2$.

- $(a,b) = (1,1)$: $\dfrac{9+14}{9} = \dfrac{23}{9}$. Not an integer.
- $(a,b) = (2,1)$: $\dfrac{36+14}{18} = \dfrac{50}{18}$. Not an integer.
- $(a,b) = (7,1)$: $\dfrac{441+14}{63} = \dfrac{455}{63} = \dfrac{65}{9}$. Not an integer.
- $(a,b) = (14,1)$: $\dfrac{1764+14}{126} = \dfrac{1778}{126} = \dfrac{889}{63}$. Not an integer.
- $(a,b) = (1,3)$: $\dfrac{9+126}{27} = \dfrac{135}{27} = 5$. Integer! $\checkmark$
- $(a,b) = (2,3)$: $\dfrac{36+126}{54} = \dfrac{162}{54} = 3$. Integer! $\checkmark$
- $(a,b) = (7,3)$: $\dfrac{441+126}{189} = \dfrac{567}{189} = 3$. Integer! $\checkmark$
- $(a,b) = (14,3)$: $\gcd(14,3)=1$. $\dfrac{1764+126}{378} = \dfrac{1890}{378} = 5$. Integer! $\checkmark$
- $(a,b) = (1,9)$: $\dfrac{9+1134}{81} = \dfrac{1143}{81} = \dfrac{127}{9}$. Not an integer.
- $(a,b) = (2,9)$: $\dfrac{36+1134}{162} = \dfrac{1170}{162} = \dfrac{65}{9}$. Not an integer.
- $(a,b) = (7,9)$: $\gcd(7,9)=1$. $\dfrac{441+1134}{567} = \dfrac{1575}{567} = \dfrac{25}{9}$. Not an integer.
- $(a,b) = (14,9)$: $\gcd(14,9)=1$. $\dfrac{1764+1134}{1134} = \dfrac{2898}{1134} = \dfrac{483}{189} = \dfrac{23}{9}$. Not an integer.

Exactly $4$ pairs work: $(1,3), (2,3), (7,3), (14,3)$.

Answer: **A**.
</Solution>
