<Problem>
The $5 \times 5$ grid shown contains a collection of squares with sizes from $1 \times 1$ to $5 \times 5$. The center unit square (in position row 3, column 3) is filled black. How many of these squares contain the black center square?
</Problem>

<Solution>
Label the grid so the black square occupies row $3$, column $3$ (counting from $1$ to $5$).

A $k \times k$ square in the grid is determined by its top-left corner at position $(r, c)$ where $1 \leq r \leq 6-k$ and $1 \leq c \leq 6-k$. It contains the black square at $(3,3)$ if and only if $r \leq 3 \leq r+k-1$ and $c \leq 3 \leq c+k-1$, i.e., $r \leq 3$ and $r \geq 4-k$, so $\max(1, 4-k) \leq r \leq 3$, and similarly for $c$.

For each $k$, the number of valid positions for $r$ (and independently $c$) is $3 - \max(1, 4-k) + 1$:
- $k=1$: $r = 3$ only, so $1$ choice. Count: $1 \times 1 = 1$.
- $k=2$: $r \in \{2,3\}$, so $2$ choices. Count: $2 \times 2 = 4$.
- $k=3$: $r \in \{1,2,3\}$, so $3$ choices. Count: $3 \times 3 = 9$.
- $k=4$: $\max(1,0) = 1$, so $r \in \{1,2,3\}$, giving $3$ choices. Count: $3 \times 3 = 9$.
- $k=5$: $r = 1$ only (only one $5\times5$ square). Count: $1 \times 1 = 1$.

Wait — for $k=4$: $4-k = 0$, so $\max(1,0)=1$, $r \in \{1,2,3\}$, $3$ choices; but also $r \leq 6-4=2$. So $r \in \{1,2\}$, only $2$ choices. Let me redo with both constraints: $\max(1,4-k) \leq r \leq \min(3, 6-k)$.

- $k=1$: $r \in [\max(1,3), \min(3,5)] = [3,3]$, $1$ choice. $1^2 = 1$.
- $k=2$: $r \in [\max(1,2), \min(3,4)] = [2,3]$, $2$ choices. $2^2 = 4$.
- $k=3$: $r \in [\max(1,1), \min(3,3)] = [1,3]$, $3$ choices. $3^2 = 9$.
- $k=4$: $r \in [\max(1,0), \min(3,2)] = [1,2]$, $2$ choices. $2^2 = 4$.
- $k=5$: $r \in [\max(1,-1), \min(3,1)] = [1,1]$, $1$ choice. $1^2 = 1$.

Total: $1 + 4 + 9 + 4 + 1 = 19$.

Answer: **D**.
</Solution>
