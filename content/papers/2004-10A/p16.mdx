<Problem>
The $5 \times 5$ grid shown contains a collection of squares with sizes from $1 \times 1$ to $5 \times 5$. The center unit square (in position row 3, column 3) is filled black. How many of these squares contain the black center square?
</Problem>

<Solution>
Label rows and columns $1$ through $5$; the black square occupies position $(3, 3)$.

A $k \times k$ square with top-left corner at $(r, c)$ contains $(3,3)$ if and only if $r \leq 3 \leq r+k-1$ and $c \leq 3 \leq c+k-1$. This requires $r \in [\max(1,\, 4-k),\, \min(3,\, 6-k)]$, and likewise for $c$. The number of valid row positions equals the number of valid column positions (by symmetry), so the count for size $k$ is the square of that number.

| $k$ | Row range | Choices |
|-----|-----------|---------|
| $1$ | $[3,3]$ | $1$ |
| $2$ | $[2,3]$ | $2$ |
| $3$ | $[1,3]$ | $3$ |
| $4$ | $[1,2]$ | $2$ |
| $5$ | $[1,1]$ | $1$ |

Total squares containing the black cell: $1^2 + 2^2 + 3^2 + 2^2 + 1^2 = 1 + 4 + 9 + 4 + 1 = 19$.

Answer: **D**.
</Solution>
