<Problem>
A box contains a collection of triangular and square tiles. There are $25$ tiles in the box, containing $84$ edges total. How many square tiles are there in the box?
</Problem>

<Solution>
Let $s$ be the number of square tiles and $t$ be the number of triangular tiles. Each square has 4 edges and each triangle has 3 edges. We get two equations:
$$s + t = 25$$
$$4s + 3t = 84$$

From the first equation, $t = 25 - s$. Substituting:
$$4s + 3(25 - s) = 84$$
$$4s + 75 - 3s = 84$$
$$s = 9.$$

Answer: **D**.
</Solution>
