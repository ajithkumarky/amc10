<Problem>
There are two values of $a$ for which the equation $4x^2 + ax + 8x + 9 = 0$ has only one solution for $x$. What is the sum of those values of $a$?
</Problem>

<Solution>
Rewrite as $4x^2 + (a+8)x + 9 = 0$. This quadratic in $x$ has exactly one solution when its discriminant is zero:
$$\Delta = (a+8)^2 - 4(4)(9) = 0 \implies (a+8)^2 = 144 \implies a+8 = \pm 12.$$

So $a = 4$ or $a = -20$. The sum of these two values is $4 + (-20) = -16$.

Answer: **A**.
</Solution>
