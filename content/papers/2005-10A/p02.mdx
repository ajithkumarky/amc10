<Problem>
For each pair of real numbers $a \neq b$, define the operation $\star$ as

$$(a \star b) = \frac{a+b}{a-b}.$$

What is the value of $\left(\left(1 \star 2\right) \star 3\right)$?
</Problem>

<Solution>
First compute $1 \star 2 = \dfrac{1+2}{1-2} = \dfrac{3}{-1} = -3$.

Then compute $(-3) \star 3 = \dfrac{-3+3}{-3-3} = \dfrac{0}{-6} = 0$.

Answer: **C**.
</Solution>
