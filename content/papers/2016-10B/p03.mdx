<Problem>
Let $x = -2016$. What is the value of $\bigg| \big||x|-x\big|-|x| \bigg| -x$?
</Problem>

<Solution>
Since $x = -2016$, we have $|x| = 2016$.

Work from the inside out:

$|x| - x = 2016 - (-2016) = 4032$.

$\big||x| - x\big| = |4032| = 4032$.

$\big||x| - x\big| - |x| = 4032 - 2016 = 2016$.

$\bigg|\big||x| - x\big| - |x|\bigg| = |2016| = 2016$.

Finally, subtract $x = -2016$:

$2016 - (-2016) = 4032$.

Answer: **D**.
</Solution>
