<Problem>
Isaac added two three-digit positive integers. All six digits in these numbers are different. Isaac's sum is a three-digit number $S$. What is the smallest possible value for the sum of the digits of $S$?
</Problem>

<Solution>
We want two three-digit numbers using six distinct digits (0–9) that add to a three-digit number $S$, and we want to minimize the digit sum of $S$.

To keep $S$ small, we want the two numbers to be as small as possible. Let's also try to produce carries that make $S$ have small digits (like $1$ or $0$).

Try to get a digit sum of $1$: that would mean $S$ is something like $100$, $200$, etc. Can we get $S = 100$? We need two 3-digit numbers summing to $100$, but the smallest 3-digit number is $100$, so their sum is at least $200$. Ruled out.

Can we get digit sum $2$? That means $S \in \{200, 110, 101, 020, \ldots\}$. Try $S = 200$: smallest pair might be something like $102 + 098$, but $098$ isn't a 3-digit number. Try $101 + 099$ — same issue. We need both addends to be 3-digit, so both $\ge 100$, meaning $S \ge 200$.

For digit sum $2$: only possibility with $S \ge 200$ is $S = 200$. We need two 3-digit numbers summing to $200$ using six different digits. E.g., $103 + 097$: $097$ is not a 3-digit integer. $190 + 010$: same issue.

Try numbers like $102 + 098$: still not valid. How about numbers entirely in range $100$–$199$? Then $S$ is between $200$ and $398$. To get digit sum $2$ with $S \ge 200$, we need $S = 200$ exactly. But $a + b = 200$ with both 3-digit and all 6 digits different: e.g., $a = 193, b = 007$ (invalid). Difficult.

Let's try digit sum $4$: e.g., $S = 400$ or $S = 310$ or $S = 301$ or $S = 130$ or $S = 103$. Try $S = 400$: $e.g., 139 + 261 = 400$ — digits used: $1,3,9,2,6,1$ — repeated $1$. Try $179 + 221 = 400$ — repeated $2$. Try $168 + 232 = 400$ — repeated $2$. Try $358 + 042 = 400$ — invalid. Try $196 + 204 = 400$ — digits: $1,9,6,2,0,4$ all different! Sum of digits of $400$ is $4+0+0=4$.

So we can achieve digit sum of $4$.

Answer: **B**.
</Solution>
