<Problem>
The mean, median, and mode of the $7$ data values $60, 100, x, 40, 50, 200, 90$ are all equal to $x$. What is the value of $x$?
</Problem>

<Solution>
**Mode:** Since $x$ must be the mode, it must appear more than once. The other six values ($60, 100, 40, 50, 200, 90$) are all distinct. So $x$ must equal one of them. But if $x$ equals one of them, it appears twice while the others appear once — that makes $x$ the unique mode. Let's keep this in mind.

**Mean:** The mean of all $7$ values equals $x$:
$$\frac{60 + 100 + x + 40 + 50 + 200 + 90}{7} = x$$
$$540 + x = 7x$$
$$540 = 6x$$
$$x = 90.$$

**Check median:** With $x = 90$, the seven values are $40, 50, 60, 90, 90, 100, 200$. Sorted, the median (4th value) is $90 = x$. ✓

**Check mode:** The value $90$ appears twice, all others once, so mode $= 90 = x$. ✓

Answer: **D**.
</Solution>
