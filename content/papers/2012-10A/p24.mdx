<Problem>
Let $a$, $b$, and $c$ be positive integers with $a \ge b \ge c$ such that
$$a^2-b^2-c^2+ab=2011 \quad \text{and} \quad a^2+3b^2+3c^2-3ab-2ac-2bc=-1997.$$
What is $a$?
</Problem>

<Solution>
**Add the two equations:**
$$(a^2-b^2-c^2+ab) + (a^2+3b^2+3c^2-3ab-2ac-2bc) = 2011 + (-1997) = 14.$$
$$2a^2 + 2b^2 + 2c^2 - 2ab - 2ac - 2bc = 14$$
$$(a^2-2ab+b^2) + (a^2-2ac+c^2) + (b^2-2bc+c^2) = 14$$
$$(a-b)^2 + (a-c)^2 + (b-c)^2 = 14.$$

Since $a \ge b \ge c > 0$, all three terms are non-negative integers. We need three perfect squares summing to 14. The possibilities (ordered $\ge$):
- $9 + 4 + 1 = 14$: $(a-b, a-c, b-c) = (3, 2, 1)$ — but $a-c = (a-b)+(b-c) = 3+1 = 4 \ne 2$. Inconsistent.
- $9 + 4 + 1$: try $(a-c)^2 = 9$, $(a-b)^2 = 4$, $(b-c)^2 = 1$: $a-c = 3, a-b = 2, b-c = 1$. Check: $2+1=3$ ✓.
- $4 + 4 + 4 + \ldots$: No, need exactly 3 squares summing to 14. Other options: $4+4+4+2$... only 3 terms. $4+4+6$? 6 not square. Unique non-trivial decomposition with ordered squares: the one above, $(a-b)^2=4, (a-c)^2=9, (b-c)^2=1$, i.e., $a-b=2, b-c=1, a-c=3$.

So $b = a - 2$ and $c = a - 3$.

**Substitute into the first equation:**
$$a^2 - (a-2)^2 - (a-3)^2 + a(a-2) = 2011.$$
$$a^2 - (a^2-4a+4) - (a^2-6a+9) + a^2 - 2a = 2011.$$
$$a^2 - a^2 + 4a - 4 - a^2 + 6a - 9 + a^2 - 2a = 2011.$$
$$8a - 13 = 2011 \implies 8a = 2024 \implies a = 253.$$

Check: $b = 251, c = 250$. Both positive and $a \ge b \ge c$ ✓.

Answer: **E**.
</Solution>
