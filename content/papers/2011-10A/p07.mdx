<Problem>
Which of the following equations does NOT have a solution?

(A) $(x+7)^2=0$

(B) $|-3x|+5=0$

(C) $\sqrt{-x}-2=0$

(D) $\sqrt{x}-8=0$

(E) $|-3x|-4=0$
</Problem>

<Solution>
Check each equation:

**(A)** $(x+7)^2 = 0$ gives $x = -7$. Solution exists.

**(B)** $|-3x| + 5 = 0$ means $|-3x| = -5$. Since absolute value is always $\geq 0$, this is impossible. No solution.

**(C)** $\sqrt{-x} = 2$ gives $-x = 4$, so $x = -4$. Solution exists.

**(D)** $\sqrt{x} = 8$ gives $x = 64$. Solution exists.

**(E)** $|-3x| = 4$ gives $3|x| = 4$, so $x = \pm\frac{4}{3}$. Solution exists.

Answer: **B**.
</Solution>
