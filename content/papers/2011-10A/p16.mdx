<Problem>
Which of the following is equal to $\sqrt{9-6\sqrt{2}}+\sqrt{9+6\sqrt{2}}$?
</Problem>

<Solution>
Simplify each radical by writing it as a perfect square.

Note $9 - 6\sqrt{2} = (\sqrt{6})^2 - 2\cdot\sqrt{6}\cdot\sqrt{3} + (\sqrt{3})^2 = (\sqrt{6}-\sqrt{3})^2$.

So $\sqrt{9-6\sqrt{2}} = \sqrt{6}-\sqrt{3}$ (positive since $\sqrt{6} > \sqrt{3}$).

Similarly $9 + 6\sqrt{2} = (\sqrt{6}+\sqrt{3})^2$, so $\sqrt{9+6\sqrt{2}} = \sqrt{6}+\sqrt{3}$.

Adding:
$$(\sqrt{6}-\sqrt{3}) + (\sqrt{6}+\sqrt{3}) = 2\sqrt{6}.$$

Answer: **B**.
</Solution>
