<Problem>
How many even integers are there between $200$ and $700$ whose digits are all different and come from the set $\{1, 2, 5, 7, 8, 9\}$?
</Problem>

<Solution>
We need 3-digit even numbers strictly between 200 and 700 (so from 201 to 699), with all digits distinct and drawn from $\{1, 2, 5, 7, 8, 9\}$.

**Even digits in our set:** $2$ and $8$.

**Valid hundreds digits** (must give a number between 200 and 700, so hundreds digit in $\{2, 5\}$, since 7xx would need to be less than 700 — but 7 is odd so if it were even it still requires hundreds digit at most 6; actually we need the number $\leq 699$, so hundreds digit $\in \{2, 5\}$ for numbers $\leq 599$, and hundreds digit $= 6$ but $6 \notin \{1,2,5,7,8,9\}$).

So valid hundreds digits from our set with the number between 200 and 699: hundreds digit $\in \{2, 5\}$.

**Case 1: Hundreds digit = 2.** Units digit must be even (from $\{2, 8\}$), but can't reuse 2, so units $= 8$. Tens digit: any of the remaining 4 digits from $\{1, 5, 7, 9\}$ (excluding 2 and 8). That gives $4$ numbers.

**Case 2: Hundreds digit = 5.** Units digit must be even: $2$ or $8$. For each choice of units digit, tens digit can be any of the remaining 4 digits from $\{1, 2, 5, 7, 8, 9\}$ minus the two used digits.

- Units $= 2$: tens from $\{1, 7, 8, 9\}$ — 4 choices.
- Units $= 8$: tens from $\{1, 2, 7, 9\}$ — 4 choices.

Case 2 gives $4 + 4 = 8$ numbers.

**Total:** $4 + 8 = 12$.

Answer: **A**.
</Solution>
