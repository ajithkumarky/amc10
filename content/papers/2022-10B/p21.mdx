<Problem>
Let $P(x)$ be a polynomial with rational coefficients such that when $P(x)$ is divided by the polynomial $x^2 + x + 1$, the remainder is $x + 2$, and when $P(x)$ is divided by the polynomial $x^2 + 1$, the remainder is $2x + 1$. There is a unique polynomial of least degree with these two properties. What is the sum of the squares of the coefficients of that polynomial?
</Problem>

<Solution>
We want a polynomial $P(x)$ with rational coefficients satisfying:
$$P(x) = (x^2+x+1)Q_1(x) + (x+2)$$
$$P(x) = (x^2+1)Q_2(x) + (2x+1)$$

for some polynomials $Q_1, Q_2$ with rational coefficients.

The minimum-degree $P$ has degree $\leq 3$ (since the LCM of $x^2+x+1$ and $x^2+1$ has degree 4, and we want the smallest degree). We write:

$$P(x) = (x^2+x+1)(x^2+1) \cdot Q(x) + R(x)$$

where $R(x)$ is the unique degree-$\leq 3$ polynomial satisfying both remainder conditions.

Let $R(x) = ax^3 + bx^2 + cx + d$.

**Condition 1:** $R(x) \equiv x+2 \pmod{x^2+x+1}$.

Divide $ax^3+bx^2+cx+d$ by $x^2+x+1$:

$x^3 = x \cdot (x^2+x+1) - x^2 - x$, so $x^3 \equiv -x^2 - x \pmod{x^2+x+1}$.

$-x^2 \equiv x + 1 \pmod{x^2+x+1}$ (since $x^2 \equiv -x-1$).

So $x^3 \equiv -(−x−1) - x = x + 1 - x = 1$... wait:

$x^2 \equiv -x-1$, so $x^3 = x \cdot x^2 \equiv x(-x-1) = -x^2 - x \equiv (x+1) - x = 1$.

Therefore: $ax^3 + bx^2 + cx + d \equiv a \cdot 1 + b(-x-1) + cx + d = a - b + d + (c-b)x \pmod{x^2+x+1}$.

Set equal to $x+2$:
$$c - b = 1 \quad \text{and} \quad a - b + d = 2. \tag{I}$$

**Condition 2:** $R(x) \equiv 2x+1 \pmod{x^2+1}$.

$x^2 \equiv -1$, so $x^3 = x \cdot x^2 \equiv -x$.

$ax^3 + bx^2 + cx + d \equiv a(-x) + b(-1) + cx + d = -b+d + (c-a)x \pmod{x^2+1}$.

Set equal to $2x+1$:
$$c - a = 2 \quad \text{and} \quad -b + d = 1. \tag{II}$$

From (I): $c = b+1$, $d = 2 - a + b$.
From (II): $c = a+2$, $d = b+1$.

Equate the two expressions for $c$: $b+1 = a+2 \Rightarrow b = a+1$.

Equate the two expressions for $d$: $2 - a + b = b+1 \Rightarrow 2-a = 1 \Rightarrow a = 1$.

So $a = 1$, $b = 2$, $c = a+2 = 3$, $d = b+1 = 3$.

**The polynomial is $P(x) = x^3 + 2x^2 + 3x + 3$.**

**Verify:**

Condition 1: Divide by $x^2+x+1$.
$x^3 + 2x^2 + 3x + 3 = (x+1)(x^2+x+1) + (x+2)$?
$(x+1)(x^2+x+1) = x^3+x^2+x+x^2+x+1 = x^3+2x^2+2x+1$.
Remainder: $(x^3+2x^2+3x+3) - (x^3+2x^2+2x+1) = x+2$ ✓

Condition 2: Divide by $x^2+1$.
$x^3+2x^2+3x+3 = (x+2)(x^2+1) + (2x+1)$?
$(x+2)(x^2+1) = x^3+x+2x^2+2 = x^3+2x^2+x+2$.
Remainder: $(x^3+2x^2+3x+3)-(x^3+2x^2+x+2) = 2x+1$ ✓

**Sum of squares of coefficients:**
$$1^2 + 2^2 + 3^2 + 3^2 = 1 + 4 + 9 + 9 = 23.$$

Answer: **E**.
</Solution>
