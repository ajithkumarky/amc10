<Problem>
Consider systems of three linear equations with unknowns $x$, $y$, and $z$,
$$a_1 x + b_1 y + c_1 z = 0$$
$$a_2 x + b_2 y + c_2 z = 0$$
$$a_3 x + b_3 y + c_3 z = 0$$
where each of the coefficients is either $0$ or $1$ and the system has a solution other than $x=y=z=0$. For example, one such system is $\{1x + 1y + 0z = 0,\ 0x + 1y + 1z = 0,\ 0x + 0y + 0z = 0\}$ with a nonzero solution of $\{x,y,z\} = \{1,-1,1\}$. How many such systems of equations are there? (The equations in a system need not be distinct, and two systems containing the same equations in a different order are considered different.)
</Problem>

Each equation has three coefficients $(a_i, b_i, c_i)$, each $0$ or $1$, so there are $2^3 = 8$ possible equations. A system of three equations is an ordered triple of these 8 equations, giving $8^3 = 512$ total systems.

We count systems that have **only** the trivial solution, then subtract from 512.

**Counting systems with only the trivial solution.** A homogeneous system $Ax = 0$ has only the trivial solution if and only if the coefficient matrix $A$ has rank 3 (i.e., is invertible). Since our matrices are $3 \times 3$ with 0-1 entries, we need $\det(A) \neq 0$.

It's easier to count matrices with $\det(A) \neq 0$ over the reals (not just mod 2). Each row is one of the 8 vectors in $\{0,1\}^3$.

We need to count ordered triples of rows $(r_1, r_2, r_3)$ from $\{0,1\}^3$ that form an invertible matrix. The total is $8^3 = 512$.

The matrices that are **not** invertible (singular) are those where the rows are linearly dependent over $\mathbb{R}$.

Let's count directly: how many ordered triples $(r_1, r_2, r_3) \in \{0,1\}^3$ give a singular matrix?

**Strategy:** Count invertible matrices instead. The determinant of a 0-1 matrix of size $3 \times 3$ is nonzero iff the rows are linearly independent over $\mathbb{R}$.
