<Problem>
Consider systems of three linear equations with unknowns $x$, $y$, and $z$,
$$a_1 x + b_1 y + c_1 z = 0$$
$$a_2 x + b_2 y + c_2 z = 0$$
$$a_3 x + b_3 y + c_3 z = 0$$
where each of the coefficients is either $0$ or $1$ and the system has a solution other than $x=y=z=0$. For example, one such system is $\{1x + 1y + 0z = 0,\ 0x + 1y + 1z = 0,\ 0x + 0y + 0z = 0\}$ with a nonzero solution of $\{x,y,z\} = \{1,-1,1\}$. How many such systems of equations are there? (The equations in a system need not be distinct, and two systems containing the same equations in a different order are considered different.)
</Problem>

<Solution>
Each equation is a row vector in $\{0,1\}^3$, giving 8 possible equations. There are $8^3 = 512$ ordered systems in total. A system has only the trivial solution exactly when the $3\times3$ coefficient matrix is invertible over $\mathbb{R}$, so we count invertible matrices and subtract.

**Invertible matrices require all three rows to be nonzero** (the zero row makes any matrix singular), so rows are chosen from the 7 nonzero vectors in $\{0,1\}^3$:

$$A=(1,0,0),\ B=(0,1,0),\ C=(0,0,1),\ D=(1,1,0),\ E=(1,0,1),\ F=(0,1,1),\ G=(1,1,1).$$

No two of these are real scalar multiples of each other (a nonzero scalar multiple of a 0-1 vector with entries $\{0,\lambda\}$ lies in $\{0,1\}^3$ only if $\lambda=1$), so every pair is linearly independent. There are $7\times 6 = 42$ ordered linearly independent pairs.

**Counting nonzero 0-1 vectors in the real span of each pair.** For a pair $(v_1,v_2)$, a third nonzero 0-1 vector $w$ lies in $\operatorname{span}_{\mathbb{R}}\{v_1,v_2\}$ iff $w = av_1+bv_2$ with all entries in $\{0,1\}$. Checking all 21 unordered pairs:

- **18 pairs** have exactly 3 nonzero 0-1 vectors in their real span (the two vectors themselves plus one more). These are all pairs except the three below.
- **3 pairs** have exactly 2 nonzero 0-1 vectors in their real span — namely $(D,E)$, $(D,F)$, and $(E,F)$. For example, $a(1,1,0)+b(1,0,1)=(a+b,a,b)$; requiring each entry in $\{0,1\}$ forces $a+b\leq 1$, so only $(a,b)\in\{(1,0),(0,1)\}$ give nonzero vectors, yielding just $D$ and $E$.

**Counting ordered invertible triples** $(v_1,v_2,v_3)$: after choosing an ordered pair, we choose $v_3$ outside the span.

- The 18 good unordered pairs give $36$ ordered pairs; for each, $v_3$ has $7-3=4$ valid choices: $36\times4=144$.
- The 3 bad unordered pairs give $6$ ordered pairs; for each, $v_3$ has $7-2=5$ valid choices: $6\times5=30$.

Total invertible matrices: $144+30=174$.

**Systems with a nontrivial solution:** $512 - 174 = 338$.

Answer: **B**.
</Solution>
