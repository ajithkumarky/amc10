<Problem>
Let $S_n$ be the sum of the first $n$ terms of an arithmetic sequence that has a common difference of $2$. The quotient $\dfrac{S_{3n}}{S_n}$ does not depend on $n$. What is $S_{20}$?
</Problem>

<Solution>
Let the first term of the arithmetic sequence be $a$ and the common difference be $2$.

The sum of the first $n$ terms of an arithmetic sequence is:
$$S_n = \frac{n}{2}(2a + (n-1) \cdot 2) = \frac{n}{2}(2a + 2n - 2) = n(a + n - 1).$$

So $S_n = n(a + n - 1)$.

Similarly:
$$S_{3n} = 3n(a + 3n - 1).$$

The quotient is:
$$\frac{S_{3n}}{S_n} = \frac{3n(a + 3n - 1)}{n(a + n - 1)} = \frac{3(a + 3n - 1)}{a + n - 1}.$$

For this to be independent of $n$, we need $\dfrac{a + 3n - 1}{a + n - 1}$ to be constant. Write $b = a - 1$, so the expression becomes $\dfrac{b + 3n}{b + n}$.

This is constant in $n$ only when the ratio of the $n$-coefficient to the constant term is the same in numerator and denominator, i.e., when $b = 0$. Let's verify: if $b \neq 0$, then $\dfrac{b + 3n}{b + n}$ depends on $n$. If $b = 0$, then $\dfrac{3n}{n} = 3$, which is constant.

So $b = 0$, meaning $a = 1$.

**Compute $S_{20}$:**

With $a = 1$ and common difference $2$:
$$S_{20} = 20(1 + 20 - 1) = 20 \cdot 20 = 400.$$

**Verification:** The sequence is $1, 3, 5, \ldots$, i.e., the odd numbers. $S_{20} = 1 + 3 + 5 + \cdots + 39 = 20^2 = 400$ ✓. And indeed $\dfrac{S_{3n}}{S_n} = \dfrac{(3n)^2}{n^2} = 9$, which is constant ✓.

Answer: **D**.
</Solution>
