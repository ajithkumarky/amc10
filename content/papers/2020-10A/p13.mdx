<Problem>
A frog sitting at the point $(1, 2)$ begins a sequence of jumps, where each jump is parallel to one of the coordinate axes and has length $1$, and the direction of each jump (up, down, right, or left) is chosen independently at random. The sequence ends when the frog reaches a side of the square with vertices $(0,0)$, $(0,4)$, $(4,4)$, and $(4,0)$. What is the probability that the sequence of jumps ends on a vertical side of the square?
</Problem>

<Solution>
Let $P(x, y)$ be the probability of ending on a vertical side ($x = 0$ or $x = 4$) starting from interior point $(x, y)$.

**Boundary conditions:**
- If $x = 0$ or $x = 4$ (vertical side): $P = 1$.
- If $y = 0$ or $y = 4$ (horizontal side): $P = 0$.

**Recurrence for interior points** ($x, y \in \{1,2,3\}$):

$$P(x,y) = \frac{P(x-1,y) + P(x+1,y) + P(x,y-1) + P(x,y+1)}{4}.$$

**Symmetry:** By the left-right symmetry (both $x=0$ and $x=4$ are vertical boundaries), $P(x,y) = P(4-x, y)$. By top-bottom symmetry (both horizontal sides give 0), $P(x,y) = P(x, 4-y)$.

This reduces to finding $P(1,1)$, $P(1,2)$, $P(2,1)$, $P(2,2)$.

Writing out the system (using symmetry to substitute $P(0,y)=P(4,y)=1$ and $P(x,0)=P(x,4)=0$):

$$4P(1,1) = 1 + P(2,1) + 0 + P(1,2)$$
$$4P(1,2) = 1 + P(2,2) + P(1,1) + P(1,1) = 1 + P(2,2) + 2P(1,1)$$
$$4P(2,1) = P(1,1) + P(1,1) + 0 + P(2,2) = 2P(1,1) + P(2,2)$$

Wait, using $P(3,y) = P(1,y)$ and $P(x,3)=P(x,1)$:

- $4P(2,2) = P(1,2) + P(3,2) + P(2,1) + P(2,3) = 2P(1,2) + 2P(2,1)$, so $P(2,2) = \tfrac{P(1,2)+P(2,1)}{2}$.
- $4P(1,2) = 1 + P(2,2) + 2P(1,1)$ (using $P(0,2)=1$, $P(1,1)=P(1,3)$).
- $4P(2,1) = 2P(1,1) + P(2,2)$ (using $P(2,0)=0$).
- $4P(1,1) = 1 + P(2,1) + P(1,2)$ (using $P(0,1)=1$, $P(1,0)=0$).

From the $P(2,2)$ equation: $P(2,2) = \tfrac{P(1,2)+P(2,1)}{2}$.

Note $4P(1,2) - 4P(2,1) = 1 - 0 = 1$ (subtracting the two middle equations), so $P(1,2) - P(2,1) = \tfrac{1}{4}$.

Let $P(2,1) = q$. Then $P(1,2) = q + \tfrac{1}{4}$.

From $4P(1,1) = 1 + q + (q + \tfrac{1}{4}) = \tfrac{5}{4} + 2q$, so $P(1,1) = \tfrac{5}{16} + \tfrac{q}{2}$.

Substituting into $4P(2,1) = 2P(1,1) + P(2,2)$:

$$4q = 2\!\left(\tfrac{5}{16}+\tfrac{q}{2}\right) + \tfrac{(q+\tfrac{1}{4})+q}{2} = \tfrac{5}{8} + q + q + \tfrac{1}{8} = \tfrac{3}{4} + 2q.$$

So $2q = \tfrac{3}{4}$, giving $q = \tfrac{3}{8}$.

Therefore $P(1,2) = \tfrac{3}{8} + \tfrac{1}{4} = \dfrac{5}{8}$.

Answer: **B**.
</Solution>
