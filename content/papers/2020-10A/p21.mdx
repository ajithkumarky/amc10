<Problem>
There exists a unique strictly increasing sequence of nonnegative integers $a_1 < a_2 < \cdots < a_k$ such that

$$\frac{2^{289}+1}{2^{17}+1} = 2^{a_1} + 2^{a_2} + \cdots + 2^{a_k}.$$

What is $k$?
</Problem>

<Solution>
Set $x = 2^{17}$, so $2^{289} = x^{17}$. Using the factorization $\dfrac{x^{17}+1}{x+1} = x^{16} - x^{15} + x^{14} - \cdots - x + 1$, we get

$$S = \frac{2^{289}+1}{2^{17}+1} = 2^{272} - 2^{255} + 2^{238} - 2^{221} + \cdots + 2^{34} - 2^{17} + 1,$$

an alternating sum of 17 terms (exponents $272, 255, 238, \ldots, 17, 0$, stepping by 17).

To write $S$ as a sum of distinct powers of 2, group consecutive positive–negative pairs from the top:

$$S = \underbrace{(2^{272} - 2^{255})}_{} + \underbrace{(2^{238} - 2^{221})}_{} + \cdots + \underbrace{(2^{34} - 2^{17})}_{} + 1.$$

There are 8 such pairs. Each pair expands via $2^{a} - 2^{a-17} = 2^{a-17}(2^{17}-1) = \sum_{j=0}^{16} 2^{a-17+j}$, contributing 17 consecutive powers of 2. The ranges are:

| Pair | Bits covered |
|---|---|
| $2^{272}-2^{255}$ | $255, 256, \ldots, 271$ |
| $2^{238}-2^{221}$ | $221, 222, \ldots, 237$ |
| $2^{204}-2^{187}$ | $187, \ldots, 203$ |
| $2^{170}-2^{153}$ | $153, \ldots, 169$ |
| $2^{136}-2^{119}$ | $119, \ldots, 135$ |
| $2^{102}-2^{85}$ | $85, \ldots, 101$ |
| $2^{68}-2^{51}$ | $51, \ldots, 67$ |
| $2^{34}-2^{17}$ | $17, \ldots, 33$ |

Plus the lone term $2^0 = 1$ (bit 0).

All 9 ranges are disjoint (consecutive ranges are separated by gaps of size 17), so $S$ is a sum of $8 \times 17 + 1 = 137$ distinct powers of 2, giving $k = 137$.

Answer: **C**.
</Solution>
