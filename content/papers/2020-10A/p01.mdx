<Problem>
What value of $x$ satisfies

$$x - \frac{3}{4} = \frac{5}{12} - \frac{1}{3}?$$
</Problem>

<Solution>
Simplify the right side first:

$$\frac{5}{12} - \frac{1}{3} = \frac{5}{12} - \frac{4}{12} = \frac{1}{12}.$$

So we need $x - \dfrac{3}{4} = \dfrac{1}{12}$.

Add $\dfrac{3}{4}$ to both sides:

$$x = \frac{1}{12} + \frac{3}{4} = \frac{1}{12} + \frac{9}{12} = \frac{10}{12} = \frac{5}{6}.$$

Answer: **E**.
</Solution>
