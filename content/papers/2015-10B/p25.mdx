<Problem>
A rectangular box measures $a \times b \times c$, where $a$, $b$, and $c$ are integers and $1 \leq a \leq b \leq c$. The volume and surface area of the box are numerically equal. How many ordered triples $(a, b, c)$ are possible?
</Problem>

<Solution>
We need $abc = 2(ab + bc + ca)$.

Rearrange: $abc = 2ab + 2bc + 2ca$. Divide both sides by $abc$:
$$1 = \frac{2}{c} + \frac{2}{a} + \frac{2}{b}.$$
$$\frac{1}{2} = \frac{1}{a} + \frac{1}{b} + \frac{1}{c}.$$

So we need to count ordered triples $(a,b,c)$ with $1 \leq a \leq b \leq c$ and integers satisfying $\dfrac{1}{a} + \dfrac{1}{b} + \dfrac{1}{c} = \dfrac{1}{2}$.

Since $a \leq b \leq c$, we have $\dfrac{1}{a} \geq \dfrac{1}{b} \geq \dfrac{1}{c}$, so $\dfrac{3}{a} \geq \dfrac{1}{2}$, giving $a \leq 6$. Also $\dfrac{1}{a} \leq \dfrac{1}{2}$, so $a \geq 3$ (since $a \geq 1$ but $1/1 + 1/b + 1/c \geq 1 > 1/2$ for $b,c \geq 1$... wait, $1/a \leq 1/2$ means $a \geq 2$. But if $a = 2$, then $1/b + 1/c = 0$, impossible. Actually $1/a < 1/2$ means $a > 2$, so $a \geq 3$.

So $3 \leq a \leq 6$.

**Case $a = 3$:** $\dfrac{1}{b} + \dfrac{1}{c} = \dfrac{1}{2} - \dfrac{1}{3} = \dfrac{1}{6}$.

With $b \leq c$ and $b \geq 3$: $\dfrac{2}{b} \geq \dfrac{1}{6} \Rightarrow b \leq 12$. Also $b \geq 7$ (since $1/b \leq 1/6$, so $b \geq 7$).

For each $b$ from 7 to 12: $c = \dfrac{6b}{b-6}$.
- $b=7$: $c = 42/1 = 42$. ✓
- $b=8$: $c = 48/2 = 24$. ✓
- $b=9$: $c = 54/3 = 18$. ✓
- $b=10$: $c = 60/4 = 15$. ✓
- $b=11$: $c = 66/5 = 13.2$. Not integer.
- $b=12$: $c = 72/6 = 12$. ✓

Solutions: $(3,7,42), (3,8,24), (3,9,18), (3,10,15), (3,12,12)$. **5 triples.**

**Case $a = 4$:** $\dfrac{1}{b} + \dfrac{1}{c} = \dfrac{1}{2} - \dfrac{1}{4} = \dfrac{1}{4}$.

$b \geq 4$, $b \leq 8$ (since $2/b \geq 1/4 \Rightarrow b \leq 8$), and $1/b \leq 1/4 \Rightarrow b \geq 5$.

- $b=5$: $c = 20/(5-4) = 20$. ✓
- $b=6$: $c = 24/2 = 12$. ✓
- $b=7$: $c = 28/3 \approx 9.3$. Not integer.
- $b=8$: $c = 32/4 = 8$. ✓

Solutions: $(4,5,20), (4,6,12), (4,8,8)$. **3 triples.**

**Case $a = 5$:** $\dfrac{1}{b} + \dfrac{1}{c} = \dfrac{1}{2} - \dfrac{1}{5} = \dfrac{3}{10}$.

$b \geq 5$, $2/b \geq 3/10 \Rightarrow b \leq 6$ (since $20/3 \approx 6.67$).

- $b=5$: $c = 50/(5\cdot 3 - 10) = 50/5 = 10$. Check: $1/5 + 1/10 = 3/10$. ✓
- $b=6$: $c = 60/(3\cdot 6 - 10) = 60/8 = 7.5$. Not integer.

Solution: $(5,5,10)$. **1 triple.**

**Case $a = 6$:** $\dfrac{1}{b} + \dfrac{1}{c} = \dfrac{1}{2} - \dfrac{1}{6} = \dfrac{1}{3}$.

$b \geq 6$, $2/b \geq 1/3 \Rightarrow b \leq 6$.

- $b=6$: $c = 18/(6-3) = 6$. Check: $1/6 + 1/6 = 1/3$. ✓

Solution: $(6,6,6)$. **1 triple.**

**Total:** $5 + 3 + 1 + 1 = 10$.

Answer: **B**.
</Solution>
