<Problem>
Let $\lfloor x \rfloor$ denote the greatest integer less than or equal to $x$. How many real numbers $x$ satisfy the equation $x^2 + 10{,}000\lfloor x \rfloor = 10{,}000x$?
</Problem>

<Solution>
Write $x = n + f$ where $n = \lfloor x \rfloor$ is an integer and $0 \le f < 1$. Substituting into $x^2 + 10000\lfloor x\rfloor = 10000x$ gives
$$n^2 + 2nf + f^2 + 10000n = 10000n + 10000f \implies f^2 + (2n-10000)f + n^2 = 0.$$

Solving this quadratic in $f$:
$$f = (5000-n) \pm \sqrt{(5000-n)^2 - n^2}.$$

The discriminant $(5000-n)^2 - n^2 = 5000(5000-2n) \ge 0$ requires $n \le 2500$. For the "$+$" branch, $f \ge 5000-n \ge 1$ whenever $n \le 4999$, so it yields no valid $f \in [0,1)$.

For the "$-$" branch, $f = (5000-n) - \sqrt{(5000-n)^2-n^2} \ge 0$ automatically (since $n \le 2500$ ensures $5000-n \ge 0$). The condition $f < 1$ requires
$$\sqrt{(5000-n)^2-n^2} > (5000-n)-1,$$
which after squaring and simplifying gives $n^2 + 2n - 9999 < 0$. The roots of $n^2+2n-9999=0$ are $n = \frac{-2 \pm 200}{2}$, i.e., $n = 99$ or $n = -101$, so the inequality holds for $-101 < n < 99$, meaning $n \in \{-100, -99, \ldots, 98\}$.

Each such integer $n$ yields exactly one valid $f$, giving $98-(-100)+1 = 199$ solutions.

Answer: **C**.
</Solution>
