<Problem>
A list of $2018$ positive integers has a unique mode, which occurs exactly $10$ times. What is the least number of distinct values that can occur in the list?
</Problem>

<Solution>
We want the minimum number of distinct values given that:
- The list has $2018$ integers total.
- One value (the mode) appears exactly $10$ times.
- All other values appear fewer than $10$ times (so at most $9$ times each) — this ensures the mode is unique.

To minimize the number of distinct values, we want all non-mode values to appear as many times as possible, i.e., exactly $9$ times each.

After placing the mode $10$ times, we have $2018 - 10 = 2008$ remaining entries. Each other distinct value can appear at most $9$ times.

Minimum number of other distinct values: $\left\lceil \frac{2008}{9} \right\rceil = \left\lceil 223.1\overline{1} \right\rceil = 224$.

Total minimum distinct values $= 1 + 224 = 225$.

Check: $1 \times 10 + 224 \times 9 = 10 + 2016 = 2026 \neq 2018$. We have $224 \times 9 = 2016 > 2008$, so we only need $223$ values at $9$ each ($223 \times 9 = 2007$) plus $1$ value appearing $2008 - 2007 = 1$ time.

That gives $1 + 223 + 1 = 225$ distinct values, using $10 + 2007 + 1 = 2018$ total ✓, and the mode (appearing $10$ times) is unique since all others appear at most $9$ times ✓.

Answer: **D**.
</Solution>
