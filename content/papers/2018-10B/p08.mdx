<Problem>
Sara makes a staircase out of toothpicks. A $3$-step staircase uses $18$ toothpicks. How many steps would be in a staircase that used $180$ toothpicks?
</Problem>

<Solution>
For an $n$-step staircase, column $k$ (for $k = 1, \ldots, n$) has $k$ squares stacked vertically. Count toothpicks by reading off the Asymptote drawing pattern: there are $\sum_{i=0}^{n-1}(n-i+1)$ horizontal toothpicks and the same number of vertical toothpicks by symmetry, giving

$$T(n) = 2\left(\frac{(n+1)(n+2)}{2} - 1\right) = (n+1)(n+2) - 2 = n^2 + 3n.$$

Check: $T(3) = 9 + 9 = 18$ ✓. Setting $T(n) = 180$:

$$n^2 + 3n - 180 = 0 \implies n = \frac{-3 + \sqrt{9 + 720}}{2} = \frac{-3 + \sqrt{729}}{2} = \frac{-3 + 27}{2} = 12.$$

Answer: **C**.
</Solution>
