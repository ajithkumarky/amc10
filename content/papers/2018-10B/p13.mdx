<Problem>
How many of the first $2018$ numbers in the sequence $101, 1001, 10001, 100001, \dots$ are divisible by $101$?
</Problem>

<Solution>
The $n$-th term of the sequence (for $n = 1, 2, 3, \ldots$) is $10^{2n} + 1$. (The 1st term is $10^2 + 1 = 101$, the 2nd is $10^4 + 1 = 10001$... wait: $1001 = 10^3 + 1$ and $10001 = 10^4 + 1$.)

Actually: $101 = 10^2 + 1$, $1001 = 10^3 + 1$, $10001 = 10^4 + 1$, $100001 = 10^5 + 1$, so the $n$-th term is $a_n = 10^{n+1} + 1$.

We need $101 \mid 10^{n+1} + 1$, i.e., $10^{n+1} \equiv -1 \pmod{101}$.

First, find the order of $10$ modulo $101$. Note $10^2 = 100 \equiv -1 \pmod{101}$.

So $10^2 \equiv -1 \pmod{101}$, which means $10^4 \equiv 1 \pmod{101}$. The order of $10$ mod $101$ is $4$.

Now $10^{n+1} \equiv -1 \pmod{101}$ iff $10^{n+1} \equiv 10^2 \pmod{101}$ iff $n+1 \equiv 2 \pmod{4}$ iff $n \equiv 1 \pmod{4}$.

So the terms divisible by $101$ are those with $n \equiv 1 \pmod{4}$: $n = 1, 5, 9, \ldots$

Among $n = 1, 2, \ldots, 2018$, those with $n \equiv 1 \pmod 4$: these are $1, 5, 9, \ldots, 2017$.

Count: $\frac{2017 - 1}{4} + 1 = \frac{2016}{4} + 1 = 504 + 1 = 505$.

Answer: **C**.
</Solution>
