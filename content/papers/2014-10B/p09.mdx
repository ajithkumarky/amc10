<Problem>
For real numbers $w$ and $z$,
$$\frac{\dfrac{1}{w} + \dfrac{1}{z}}{\dfrac{1}{w} - \dfrac{1}{z}} = 2014.$$
What is $\dfrac{w+z}{w-z}$?
</Problem>

<Solution>
Simplify the left side by writing $\dfrac{1}{w} + \dfrac{1}{z} = \dfrac{z+w}{wz}$ and $\dfrac{1}{w} - \dfrac{1}{z} = \dfrac{z-w}{wz}$:

$$\frac{\frac{z+w}{wz}}{\frac{z-w}{wz}} = \frac{z+w}{z-w} = 2014.$$

We want $\dfrac{w+z}{w-z}$. Since $\dfrac{z+w}{z-w} = 2014$, we have:
$$\frac{w+z}{w-z} = \frac{z+w}{-(z-w)} = -\frac{z+w}{z-w} = -2014.$$

Answer: **A**.
</Solution>
