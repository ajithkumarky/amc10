<Problem>
The first four terms in an arithmetic sequence are $x + y$, $x - y$, $xy$, and $x/y$, in that order. What is the fifth term?
</Problem>

<Solution>
In an arithmetic sequence the common difference is constant, so:
$$(x-y) - (x+y) = xy - (x-y) = \frac{x}{y} - xy.$$

From the first equality: $-2y = xy - x + y$, giving $xy - x + 3y = 0$, so $x(y-1) = -3y$, thus:
$$x = \frac{-3y}{y-1}.$$

From the second equality: $xy - x + y = \dfrac{x}{y} - xy$, so $2xy - x + y = \dfrac{x}{y}$.

Multiply through by $y$: $2xy^2 - xy + y^2 = x$, giving $x(2y^2 - y - 1) = -y^2$:
$$x(2y+1)(y-1) = -y^2.$$

Substituting $x = \dfrac{-3y}{y-1}$:
$$\frac{-3y}{y-1}(2y+1)(y-1) = -y^2$$
$$-3y(2y+1) = -y^2$$
$$3(2y+1) = y \quad \text{(dividing by } -y, y \neq 0\text{)}$$
$$6y + 3 = y$$
$$5y = -3 \implies y = -\frac{3}{5}.$$

Then $x = \dfrac{-3(-3/5)}{-3/5 - 1} = \dfrac{9/5}{-8/5} = -\dfrac{9}{8}$.

**Verify the sequence:**
- $x + y = -\dfrac{9}{8} - \dfrac{3}{5} = -\dfrac{45}{40} - \dfrac{24}{40} = -\dfrac{69}{40}$
- $x - y = -\dfrac{9}{8} + \dfrac{3}{5} = -\dfrac{45}{40} + \dfrac{24}{40} = -\dfrac{21}{40}$
- Common difference $d = \left(-\dfrac{21}{40}\right) - \left(-\dfrac{69}{40}\right) = \dfrac{48}{40} = \dfrac{6}{5}$
- $xy = \left(-\dfrac{9}{8}\right)\left(-\dfrac{3}{5}\right) = \dfrac{27}{40}$. Check: $-\dfrac{21}{40} + \dfrac{6}{5} = -\dfrac{21}{40} + \dfrac{48}{40} = \dfrac{27}{40}$ ✓
- $x/y = \dfrac{-9/8}{-3/5} = \dfrac{9}{8} \cdot \dfrac{5}{3} = \dfrac{15}{8}$. Check: $\dfrac{27}{40} + \dfrac{6}{5} = \dfrac{27}{40} + \dfrac{48}{40} = \dfrac{75}{40} = \dfrac{15}{8}$ ✓

**Fifth term:** $\dfrac{15}{8} + \dfrac{6}{5} = \dfrac{75}{40} + \dfrac{48}{40} = \dfrac{123}{40}$.

Answer: **E**.
</Solution>
