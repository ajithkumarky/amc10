<Problem>
Suppose that the number $a$ satisfies the equation $4 = a + a^{-1}$. What is the value of $a^{4} + a^{-4}$?
</Problem>

<Solution>
Start from $a + a^{-1} = 4$ and build up by squaring repeatedly.

**Square once:**
$$(a + a^{-1})^2 = a^2 + 2 + a^{-2} = 16 \implies a^2 + a^{-2} = 14.$$

**Square again:**
$$(a^2 + a^{-2})^2 = a^4 + 2 + a^{-4} = 196 \implies a^4 + a^{-4} = 194.$$

Answer: **D**.
</Solution>
