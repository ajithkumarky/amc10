<Problem>
Real numbers $a$ and $b$ satisfy the equations $3^{a} = 81^{b+2}$ and $125^{b} = 5^{a-3}$. What is $ab$?
</Problem>

<Solution>
Rewrite each equation using common bases.

**First equation:** $3^a = 81^{b+2} = 3^{4(b+2)}$, so:
$$a = 4b + 8. \quad (1)$$

**Second equation:** $125^b = 5^{a-3}$, i.e., $5^{3b} = 5^{a-3}$, so:
$$3b = a - 3 \implies a = 3b + 3. \quad (2)$$

From (1) and (2): $4b + 8 = 3b + 3 \implies b = -5$.

Then $a = 3(-5) + 3 = -12$.

Therefore $ab = (-12)(-5) = 60$.

Answer: **E**.
</Solution>
