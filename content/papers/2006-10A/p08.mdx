<Problem>
A parabola with equation $y = x^2 + bx + c$ passes through the points $(2, 3)$ and $(4, 3)$.  What is $c$?
</Problem>

<Solution>
Since both points have the same $y$-value of 3, the axis of symmetry lies halfway between $x = 2$ and $x = 4$, so the vertex is at $x = 3$.

For a parabola $y = x^2 + bx + c$, the axis of symmetry is $x = -\dfrac{b}{2}$, so $-\dfrac{b}{2} = 3$, giving $b = -6$.

Now substitute the point $(2, 3)$:
$$3 = 4 + (-6)(2) + c = 4 - 12 + c = c - 8.$$
$$c = 11.$$

Answer: **E**.
</Solution>
