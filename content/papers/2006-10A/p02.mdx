<Problem>
Define $x \otimes y = x^3 - y$. What is $h \otimes (h \otimes h)$?
</Problem>

<Solution>
First compute the inner operation: $h \otimes h = h^3 - h$.

Then apply the outer operation:
$$h \otimes (h^3 - h) = h^3 - (h^3 - h) = h^3 - h^3 + h = h.$$

Answer: **C**.
</Solution>
