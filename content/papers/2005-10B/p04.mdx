<Problem>
For real numbers $a$ and $b$, define $a \diamond b = \sqrt{a^2 + b^2}$. What is the value of

$$(5 \diamond 12) \diamond ((-12) \diamond (-5))?$$
</Problem>

<Solution>
First evaluate each inner expression:
$$5 \diamond 12 = \sqrt{5^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13.$$
$$(-12) \diamond (-5) = \sqrt{(-12)^2 + (-5)^2} = \sqrt{144 + 25} = \sqrt{169} = 13.$$

Then:
$$13 \diamond 13 = \sqrt{13^2 + 13^2} = \sqrt{2 \cdot 169} = 13\sqrt{2}.$$

Answer: **D**.
</Solution>
