<Problem>
In $\triangle ABC$, we have $AC = BC = 7$ and $AB = 2$. Suppose that $D$ is a point on line $AB$ such that $B$ lies between $A$ and $D$ and $CD = 8$. What is $BD$?
</Problem>

<Solution>
Place $A = (-1, 0)$ and $B = (1, 0)$ so $AB = 2$. Since $AC = BC = 7$, point $C$ is on the perpendicular bisector of $AB$, so $C = (0, h)$ where $h = \sqrt{49 - 1} = \sqrt{48} = 4\sqrt{3}$.

$D$ is on ray $BA$ beyond $B$, so $D = (1 + t, 0)$ for some $t > 0$, where $BD = t$.

$$CD = \sqrt{(1+t)^2 + 48} = 8.$$
$$(1+t)^2 + 48 = 64 \implies (1+t)^2 = 16 \implies 1 + t = 4 \implies t = 3.$$

So $BD = 3$.

Answer: **A**.
</Solution>
