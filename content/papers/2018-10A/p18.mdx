<Problem>
How many nonnegative integers can be written in the form $$a_7 \cdot 3^7 + a_6 \cdot 3^6 + a_5 \cdot 3^5 + a_4 \cdot 3^4 + a_3 \cdot 3^3 + a_2 \cdot 3^2 + a_1 \cdot 3^1 + a_0 \cdot 3^0,$$ where $a_i \in \{-1, 0, 1\}$ for $0 \leq i \leq 7$?
</Problem>

<Solution>
This is the "balanced ternary" representation using $8$ digits, each from $\{-1, 0, 1\}$.

**Range of representable values:**

- Maximum value (all $a_i = 1$): $3^0 + 3^1 + \cdots + 3^7 = \frac{3^8 - 1}{2} = \frac{6561 - 1}{2} = 3280$.
- Minimum value (all $a_i = -1$): $-3280$.

**Total distinct integers representable:**

Each of the $8$ positions can independently be $-1$, $0$, or $1$, giving $3^8 = 6561$ combinations. However, different combinations can give the same integer value. In balanced ternary with $8$ digits ($3^0$ through $3^7$), each integer in $[-3280, 3280]$ has a unique representation (this is a property of balanced ternary). So there are exactly $3^8 = 6561$ distinct integers representable (all integers from $-3280$ to $3280$).

**Count of nonnegative integers:**

The total $6561$ integers are symmetric around $0$ (for every representation giving value $v$, negating all $a_i$ gives $-v$). The number of nonnegative values is:

$$\frac{6561 - 1}{2} + 1 = 3280 + 1 = 3281.$$

(The $-1$ accounts for $0$ being counted once, and we add $1$ for $0$ itself.)

Answer: **D**.
</Solution>
