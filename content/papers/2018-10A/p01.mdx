<Problem>
What is the value of $$\left(\left((2+1)^{-1}+1\right)^{-1}+1\right)^{-1}+1?$$
</Problem>

<Solution>
Work from the inside out.

Start with the innermost expression: $2 + 1 = 3$, so $(2+1)^{-1} = \dfrac{1}{3}$.

Next layer: $\dfrac{1}{3} + 1 = \dfrac{4}{3}$, so $\left(\dfrac{4}{3}\right)^{-1} = \dfrac{3}{4}$.

Next layer: $\dfrac{3}{4} + 1 = \dfrac{7}{4}$, so $\left(\dfrac{7}{4}\right)^{-1} = \dfrac{4}{7}$.

Final step: $\dfrac{4}{7} + 1 = \dfrac{11}{7}$.

Answer: **B**.
</Solution>
