<Problem>
An integer $N$ is selected at random in the range $1 \leq N \leq 2020$. What is the probability that the remainder when $N^{16}$ is divided by $5$ is $1$?
</Problem>

<Solution>
By Fermat's Little Theorem, for $\gcd(N, 5) = 1$ (i.e., $5 \nmid N$), we have $N^4 \equiv 1 \pmod{5}$. Therefore $N^{16} = (N^4)^4 \equiv 1^4 = 1 \pmod{5}$.

If $5 \mid N$, then $N^{16} \equiv 0 \pmod{5}$, which is not $1$.

So $N^{16} \equiv 1 \pmod 5$ if and only if $5 \nmid N$.

Among $1$ through $2020$: exactly $\dfrac{2020}{5} = 404$ multiples of $5$.

Numbers not divisible by $5$: $2020 - 404 = 1616$.

Probability: $\dfrac{1616}{2020} = \dfrac{4}{5}$.

Answer: **D**.
</Solution>
