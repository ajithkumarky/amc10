<Problem>
How many strings of length $5$ formed from the digits $0, 1, 2, 3, 4$ are there such that for each $j \in \{1, 2, 3, 4\}$, at least $j$ of the digits are less than $j$? (For example, $02214$ satisfies this condition because it contains at least $1$ digit less than $1$, at least $2$ digits less than $2$, at least $3$ digits less than $3$, and at least $4$ digits less than $4$. The string $23404$ does not satisfy the condition because it does not contain at least $2$ digits less than $2$.)
</Problem>

<Solution>
Let $n_k$ = number of times digit $k$ appears in the string ($k=0,1,2,3,4$), so $\sum n_k = 5$. The condition "at least $j$ digits are less than $j$" translates to:
$$n_0 \geq 1, \quad n_0+n_1 \geq 2, \quad n_0+n_1+n_2 \geq 3, \quad n_0+n_1+n_2+n_3 \geq 4 \;(\text{i.e., }n_4 \leq 1).$$

Each frequency tuple $(n_0,n_1,n_2,n_3,n_4)$ contributes $\dfrac{5!}{n_0!\,n_1!\,n_2!\,n_3!\,n_4!}$ ordered strings. Enumerate all valid tuples and sum their multinomials:

**$n_0=1$** (so $n_1 \geq 1$, $n_1+n_2 \geq 1$, $n_1+n_2+n_3 \geq 2$, $n_4 \leq 1$):

| $(n_0,n_1,n_2,n_3,n_4)$ | count |
|---|---|
| $(1,1,1,1,1)$ | $120$ |
| $(1,1,1,2,0)$ | $60$ |
| $(1,1,2,0,1)$ | $60$ |
| $(1,1,2,1,0)$ | $60$ |
| $(1,1,3,0,0)$ | $20$ |
| $(1,2,0,1,1)$ | $60$ |
| $(1,2,0,2,0)$ | $30$ |
| $(1,2,1,0,1)$ | $60$ |
| $(1,2,1,1,0)$ | $60$ |
| $(1,2,2,0,0)$ | $30$ |
| $(1,3,0,0,1)$ | $20$ |
| $(1,3,0,1,0)$ | $20$ |
| $(1,3,1,0,0)$ | $20$ |
| $(1,4,0,0,0)$ | $5$ |

Subtotal: $\mathbf{625}$.

**$n_0=2$** (so $n_1+n_2 \geq 1$ when $n_1=0$; $n_1+n_2+n_3 \geq 2$ when $n_0+n_1+n_2 < 4$):

| $(n_0,n_1,n_2,n_3,n_4)$ | count |
|---|---|
| $(2,0,1,1,1)$ | $60$ |
| $(2,0,1,2,0)$ | $30$ |
| $(2,0,2,0,1)$ | $30$ |
| $(2,0,2,1,0)$ | $30$ |
| $(2,0,3,0,0)$ | $10$ |
| $(2,1,0,1,1)$ | $60$ |
| $(2,1,0,2,0)$ | $30$ |
| $(2,1,1,0,1)$ | $60$ |
| $(2,1,1,1,0)$ | $60$ |
| $(2,1,2,0,0)$ | $30$ |
| $(2,2,0,0,1)$ | $30$ |
| $(2,2,0,1,0)$ | $30$ |
| $(2,2,1,0,0)$ | $30$ |
| $(2,3,0,0,0)$ | $10$ |

Subtotal: $160+240+90+10 = \mathbf{500}$.

**$n_0=3$**:

| $(n_0,n_1,n_2,n_3,n_4)$ | count |
|---|---|
| $(3,0,0,1,1)$ | $20$ |
| $(3,0,0,2,0)$ | $10$ |
| $(3,0,1,0,1)$ | $20$ |
| $(3,0,1,1,0)$ | $20$ |
| $(3,0,2,0,0)$ | $10$ |
| $(3,1,0,0,1)$ | $20$ |
| $(3,1,0,1,0)$ | $20$ |
| $(3,1,1,0,0)$ | $20$ |
| $(3,2,0,0,0)$ | $10$ |

Subtotal: $80+60+10 = \mathbf{150}$.

**$n_0=4$**: tuples $(4,1,0,0,0), (4,0,1,0,0), (4,0,0,1,0), (4,0,0,0,1)$, each giving $5$. Subtotal: $\mathbf{20}$.

**$n_0=5$**: $(5,0,0,0,0)$ gives $1$. Subtotal: $\mathbf{1}$.

**Grand total:** $625 + 500 + 150 + 20 + 1 = \mathbf{1296}$.

Answer: **E**.
</Solution>
