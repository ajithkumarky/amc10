<Problem>
Isosceles trapezoid $ABCD$ has parallel sides $\overline{AD}$ and $\overline{BC}$, with $BC < AD$ and $AB = CD$. There is a point $P$ in the plane such that $PA = 1$, $PB = 2$, $PC = 3$, and $PD = 4$. What is $\dfrac{BC}{AD}$?
</Problem>

<Solution>
**Use Ptolemy-like relations.** Since $ABCD$ is an isosceles trapezoid, it is a cyclic quadrilateral (inscribed in a circle). Apply the British Flag Theorem generalization, or use the following approach.

**Set up coordinates.** Place $AD$ along the $x$-axis with center at the origin: $A = (-a, 0)$, $D = (a, 0)$, so $AD = 2a$. By symmetry, $B = (-b, h)$, $C = (b, h)$, so $BC = 2b$, with $b < a$ and $h > 0$.

Let $P = (x, y)$. We have:
$$PA^2 = (x+a)^2 + y^2 = 1,$$
$$PB^2 = (x+b)^2 + (y-h)^2 = 4,$$
$$PC^2 = (x-b)^2 + (y-h)^2 = 9,$$
$$PD^2 = (x-a)^2 + y^2 = 16.$$

**From $PA^2$ and $PD^2$:**
$$PD^2 - PA^2 = (x-a)^2 - (x+a)^2 = -4ax = 15,$$
so $x = -\dfrac{15}{4a}$.

**From $PA^2 + PD^2$:**
$$PA^2 + PD^2 = 2x^2 + 2a^2 + 2y^2 = 17,$$
$$x^2 + y^2 + a^2 = \frac{17}{2}.$$

**From $PB^2$ and $PC^2$:**
$$PC^2 - PB^2 = (x-b)^2 - (x+b)^2 = -4bx = 5,$$
so $x = -\dfrac{5}{4b}$.

**Relate $a$ and $b$:** From the two expressions for $x$:
$$-\frac{15}{4a} = -\frac{5}{4b} \implies \frac{15}{a} = \frac{5}{b} \implies b = \frac{a}{3}.$$

Therefore:
$$\frac{BC}{AD} = \frac{2b}{2a} = \frac{b}{a} = \frac{1}{3}.$$

**Verify consistency** (to confirm such a configuration exists): from $PC^2 + PB^2$:
$$PB^2 + PC^2 = 2x^2 + 2b^2 + 2(y-h)^2 = 13,$$
$$x^2 + b^2 + (y-h)^2 = \frac{13}{2}.$$

We have $x = -\dfrac{5}{4b}$ and $b = \dfrac{a}{3}$.  With $a$ determined by $x^2 + y^2 + a^2 = \dfrac{17}{2}$, we can find valid $a, h, y$. The existence is guaranteed by the problem statement.

Answer: **B**.
</Solution>
