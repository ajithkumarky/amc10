<Problem>
The positive integers $A$, $B$, $A-B$, and $A+B$ are all prime numbers. The sum of these four primes is
</Problem>

<Solution>
Since $A - B > 0$, we need $A > B$. Both $A$ and $B$ are prime, and $A - B$ is also prime.

The only even prime is $2$. Since $A + B$ and $A - B$ have the same parity as $A + B$ and $A - B$:

- If both $A$ and $B$ are odd, then $A - B$ and $A + B$ are both even. The only even prime is $2$, but $A + B \geq 2 + 3 = 5 > 2$, so $A + B$ would be even and greater than $2$, hence not prime. Contradiction.

- Therefore exactly one of $A$, $B$ is even, meaning one of them is $2$.

If $B = 2$: then $A - 2$ and $A + 2$ must both be prime, with $A$ also prime. Testing small primes for $A$:
  - $A = 3$: $A-B = 1$ (not prime). ✗
  - $A = 5$: $A-B = 3$ ✓, $A+B = 7$ ✓. All four primes: $5, 2, 3, 7$. ✓

If $A = 2$: then $B < A = 2$ means $B = 1$, not prime. ✗

So the only solution is $A=5$, $B=2$, giving primes $5, 2, 3, 7$.

Sum $= 5 + 2 + 3 + 7 = 17$, which is prime.

Answer: **E**.
</Solution>
