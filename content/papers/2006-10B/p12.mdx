<Problem>
The lines $x = \dfrac{1}{4}y + a$ and $y = \dfrac{1}{4}x + b$ intersect at the point $(1, 2)$. What is $a + b$?
</Problem>

<Solution>
Substitute $(1, 2)$ into each equation.

From $x = \dfrac{1}{4}y + a$: $1 = \dfrac{1}{4}(2) + a = \dfrac{1}{2} + a$, so $a = \dfrac{1}{2}$.

From $y = \dfrac{1}{4}x + b$: $2 = \dfrac{1}{4}(1) + b = \dfrac{1}{4} + b$, so $b = \dfrac{7}{4}$.

Therefore $a + b = \dfrac{1}{2} + \dfrac{7}{4} = \dfrac{2}{4} + \dfrac{7}{4} = \dfrac{9}{4}$.

Answer: **E**.
</Solution>
