<Problem>
Which of the following is equivalent to $\sqrt{\dfrac{x}{1-\dfrac{x-1}{x}}}$ when $x < 0$?
</Problem>

<Solution>
Simplify the expression inside the square root. The denominator is:
$$1 - \frac{x-1}{x} = \frac{x - (x-1)}{x} = \frac{1}{x}.$$

So the expression becomes:
$$\sqrt{\frac{x}{1/x}} = \sqrt{x \cdot x} = \sqrt{x^2} = |x|.$$

Since $x < 0$, we have $|x| = -x$.

Answer: **A**.
</Solution>
