<Problem>
Let $a_1, a_2, \ldots$ be a sequence for which $a_1 = 2$, $a_2 = 3$, and $a_n = \dfrac{a_{n-1}}{a_{n-2}}$ for each positive integer $n \ge 3$. What is $a_{2006}$?
</Problem>

<Solution>
Compute the first several terms to find the period:
- $a_1 = 2$
- $a_2 = 3$
- $a_3 = \dfrac{3}{2}$
- $a_4 = \dfrac{3/2}{3} = \dfrac{1}{2}$
- $a_5 = \dfrac{1/2}{3/2} = \dfrac{1}{3}$
- $a_6 = \dfrac{1/3}{1/2} = \dfrac{2}{3}$
- $a_7 = \dfrac{2/3}{1/3} = 2 = a_1$
- $a_8 = \dfrac{2}{2/3} = 3 = a_2$

The sequence is periodic with period 6. Since $2006 = 6 \times 334 + 2$, we have $a_{2006} = a_2 = 3$.

Answer: **E**.
</Solution>
