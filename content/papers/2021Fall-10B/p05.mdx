<Problem>
Let $n = 8^{2022}$. Which of the following is equal to $\dfrac{n}{4}$?
</Problem>

<Solution>
Write everything as a power of 2.

$$n = 8^{2022} = (2^3)^{2022} = 2^{6066}.$$

$$\frac{n}{4} = \frac{2^{6066}}{2^2} = 2^{6064}.$$

Now check each choice:

- $4^{1010} = 2^{2020}$ — no.
- $2^{2022}$ — no.
- $8^{2018} = 2^{6054}$ — no.
- $4^{3031} = 2^{6062}$ — no.
- $4^{3032} = 2^{6064}$ — yes!

Answer: **E**.
</Solution>
