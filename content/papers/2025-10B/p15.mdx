<Problem>
The sum
$$\sum_{k=1}^{\infty} \frac{1}{k^3 + 6k^2 + 8k}$$
can be expressed as $\dfrac{a}{b}$, where $a$ and $b$ are relatively prime positive integers. What is $a + b$?
</Problem>

<Solution>
**Factor the denominator.** We have
$$k^3 + 6k^2 + 8k = k(k^2 + 6k + 8) = k(k+2)(k+4).$$

**Partial fractions.** Write
$$\frac{1}{k(k+2)(k+4)} = \frac{A}{k} + \frac{B}{k+2} + \frac{C}{k+4}.$$

Multiply both sides by $k(k+2)(k+4)$:
$$1 = A(k+2)(k+4) + Bk(k+4) + Ck(k+2).$$

- Set $k = 0$: $1 = A \cdot 2 \cdot 4 = 8A$, so $A = \tfrac{1}{8}$.
- Set $k = -2$: $1 = B(-2)(2) = -4B$, so $B = -\tfrac{1}{4}$.
- Set $k = -4$: $1 = C(-4)(-2) = 8C$, so $C = \tfrac{1}{8}$.

Thus
$$\frac{1}{k(k+2)(k+4)} = \frac{1}{8}\cdot\frac{1}{k} - \frac{1}{4}\cdot\frac{1}{k+2} + \frac{1}{8}\cdot\frac{1}{k+4}.$$

**Rewrite as a telescoping difference.** Notice
$$\frac{1}{8}\cdot\frac{1}{k} - \frac{1}{4}\cdot\frac{1}{k+2} + \frac{1}{8}\cdot\frac{1}{k+4} = \frac{1}{8}\left(\frac{1}{k} - \frac{2}{k+2} + \frac{1}{k+4}\right).$$

We can split further:
$$\frac{1}{k} - \frac{2}{k+2} + \frac{1}{k+4} = \left(\frac{1}{k} - \frac{1}{k+2}\right) - \left(\frac{1}{k+2} - \frac{1}{k+4}\right).$$

Let $f(k) = \dfrac{1}{k} - \dfrac{1}{k+2}$. Then our term equals $\dfrac{1}{8}\bigl[f(k) - f(k+2)\bigr]$.

**Sum telescopes:**
$$\sum_{k=1}^{\infty} \frac{1}{k(k+2)(k+4)} = \frac{1}{8}\sum_{k=1}^{\infty}\bigl[f(k) - f(k+2)\bigr].$$

This is a telescoping sum with step 2, so we split into odd and even $k$:

For odd $k = 1, 3, 5, \ldots$:
$$\sum_{\substack{k=1 \\ k \text{ odd}}}^{\infty}[f(k)-f(k+2)] = f(1).$$

For even $k = 2, 4, 6, \ldots$:
$$\sum_{\substack{k=2 \\ k \text{ even}}}^{\infty}[f(k)-f(k+2)] = f(2).$$

So the total sum is $\dfrac{1}{8}[f(1) + f(2)]$.

$$f(1) = \frac{1}{1} - \frac{1}{3} = \frac{2}{3}, \qquad f(2) = \frac{1}{2} - \frac{1}{4} = \frac{1}{4}.$$

$$S = \frac{1}{8}\left(\frac{2}{3} + \frac{1}{4}\right) = \frac{1}{8} \cdot \frac{8+3}{12} = \frac{1}{8} \cdot \frac{11}{12} = \frac{11}{96}.$$

**Check gcd:** $\gcd(11, 96) = 1$, so $a = 11$, $b = 96$, and $a + b = 107$.

Answer: **D**.
</Solution>
