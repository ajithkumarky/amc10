<Problem>
How many ordered triples of integers $(x, y, z)$ satisfy the following system of inequalities?

$$-x - y - z \leq -2$$
$$-x + y + z \leq 2$$
$$x - y + z \leq 2$$
$$x + y - z \leq 2$$
</Problem>

<Solution>
Rewrite the first inequality as $x + y + z \geq 2$.

**Step 1: Show $x, y, z \geq 0$.**

Subtract the second inequality from the first: $(x+y+z) - (-x+y+z) = 2x \geq 0$, so $x \geq 0$. Similarly subtracting the third from the first gives $2y \geq 0$, and subtracting the fourth gives $2z \geq 0$.

**Step 2: Upper bound on $x + y + z$.**

Add the last three inequalities: $(-x+y+z)+(x-y+z)+(x+y-z) = x+y+z \leq 2+2+2 = 6$.

So we need non-negative integers with $2 \leq x+y+z \leq 6$, and the constraints:
$$-x+y+z \leq 2, \quad x-y+z \leq 2, \quad x+y-z \leq 2.$$

Let $s = x+y+z$. For a triple with sum $s$, constraint $-x+y+z \leq 2$ means $s - 2x \leq 2$, i.e., $x \geq \frac{s-2}{2}$. Similarly $y \geq \frac{s-2}{2}$ and $z \geq \frac{s-2}{2}$.

**$s = 2$:** Each variable $\geq 0$. No further restriction (since $\frac{s-2}{2}=0$). Count of non-negative integer triples summing to $2$: $\binom{4}{2} = 6$.

**$s = 3$:** Each variable $\geq \frac{1}{2}$, so $\geq 1$ (integers). Positive integer triples summing to $3$: only $(1,1,1)$. Count: $1$.

**$s = 4$:** Each variable $\geq 1$. Positive integer triples summing to $4$: $(2,1,1),(1,2,1),(1,1,2)$. Count: $3$.

**$s = 5$:** Each variable $\geq \frac{3}{2}$, so $\geq 2$. Three variables each $\geq 2$ sum to at least $6 > 5$. Count: $0$.

**$s = 6$:** Each variable $\geq 2$. Only $(2,2,2)$ sums to $6$. But check: $-x+y+z = -2+2+2 = 2 \leq 2$. Yes! Count: $1$.

**Total:** $6 + 1 + 3 + 0 + 1 = 11$.

Answer: **C**.
</Solution>
