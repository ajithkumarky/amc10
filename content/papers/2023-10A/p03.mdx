<Problem>
How many positive perfect squares less than $2023$ are divisible by $5$?
</Problem>

<Solution>
If a perfect square $n^2$ is divisible by $5$, then $5 \mid n^2$, which forces $5 \mid n$ (since 5 is prime). So $n = 5k$ for some positive integer $k$, giving $n^2 = 25k^2$.

We need $25k^2 < 2023$, so $k^2 < \dfrac{2023}{25} = 80.92$, meaning $k \le 8$.

The values $k = 1, 2, 3, 4, 5, 6, 7, 8$ each produce a valid perfect square: $25, 100, 225, 400, 625, 900, 1225, 1600$ — all less than 2023.

That gives $\mathbf{8}$ such perfect squares.

Answer: **A**.
</Solution>
