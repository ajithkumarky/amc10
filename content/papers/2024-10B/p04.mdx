<Problem>
Balls numbered $1, 2, 3, \ldots$ are placed in bins $A$, $B$, $C$, $D$, and $E$ so that the first ball is placed in $A$, the next two are placed in $B$, the next three are placed in $C$, the next four are placed in $D$, the next five are placed in $E$, and then the next six go in $A$, etc. For example, $22, 23, \ldots, 28$ are placed in $B$. Which bin contains ball $2024$?
</Problem>

<Solution>
The group sizes cycle through the bins $A, B, C, D, E$ with ever-increasing sizes. In round $k$ (starting at $k=1$), the five groups have sizes $5(k-1)+1,\; 5(k-1)+2,\; 5(k-1)+3,\; 5(k-1)+4,\; 5(k-1)+5$, which sum to $25(k-1)+15$.

The total number of balls placed through the end of round $k$ is:

$$\sum_{j=1}^{k} [25(j-1)+15] = 25\cdot\frac{k(k-1)}{2} + 15k = \frac{k(25k-10)}{2} + 15k = \frac{25k^2 + 5k}{2}.$$

Find the last completed round before ball 2024. Set $\dfrac{25k^2+5k}{2} < 2024$:

- $k=12$: $\dfrac{25\cdot144+60}{2} = \dfrac{3660}{2} = 1830$. Ball 1830 ends round 12.
- $k=13$: $\dfrac{25\cdot169+65}{2} = \dfrac{4290}{2} = 2145 > 2024$.

So ball 2024 falls in round 13. In round 13, the group sizes are:
- $A$: size $61$, balls $1831$–$1891$
- $B$: size $62$, balls $1892$–$1953$
- $C$: size $63$, balls $1954$–$2016$
- $D$: size $64$, balls $2017$–$2080$

Since $2017 \le 2024 \le 2080$, ball 2024 is in bin $D$.

Answer: **D**.
</Solution>
