<Problem>
The Fibonacci sequence $1, 1, 2, 3, 5, 8, 13, 21, \ldots$ starts with two $1$s, and each term afterwards is the sum of its two predecessors. Which one of the ten digits is the last to appear in the units position of a number in the Fibonacci sequence?
</Problem>

<Solution>
The units digits of the Fibonacci sequence repeat with period 60 (the Pisano period for mod 10). We list the units digits:

$1, 1, 2, 3, 5, 8, 3, 1, 4, 5, 9, 4, 3, 7, 0, 7, 7, 4, 1, 5, 6, 1, 7, 8, 5, 3, 8, 1, 9, 0, 9, 9, 8, 7, 5, 2, 7, 9, 6, 5, 1, 6, 7, 3, 0, 3, 3, 6, 9, 5, 4, 9, 3, 2, 5, 7, 2, 9, 1, 0, \ldots$

Scanning for each digit's first appearance:
- $0$: position 15
- $1$: position 1
- $2$: position 3
- $3$: position 4
- $4$: position 9
- $5$: position 5
- $6$: position 21
- $7$: position 14
- $8$: position 6
- $9$: position 11

The digit $6$ first appears at position 21, which is later than all other digits. Therefore $6$ is the last digit to appear.

Answer: **C**.
</Solution>
