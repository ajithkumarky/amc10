<Problem>
A function $f : \mathbb{R} \to \mathbb{R}$ satisfies

$$f(xy) = f(x) + f(y) - f(x)\,f(y)$$

for all real numbers $x$ and $y$. If $f(2) = \dfrac{1}{3}$, what is $f(8)$?
</Problem>

<Solution>
**Key substitution:** Define $g(x) = 1 - f(x)$. Substituting $f(x) = 1 - g(x)$ into the functional equation:

$$1 - g(xy) = \bigl(1 - g(x)\bigr) + \bigl(1 - g(y)\bigr) - \bigl(1 - g(x)\bigr)\bigl(1 - g(y)\bigr).$$

Expand the right side:

$$= 2 - g(x) - g(y) - \bigl(1 - g(x) - g(y) + g(x)g(y)\bigr) = 1 - g(x)g(y).$$

So $1 - g(xy) = 1 - g(x)g(y)$, which gives:

$$g(xy) = g(x)\,g(y).$$

The function $g$ is **multiplicative**.

**Using multiplicativity:**

$$g(2) = 1 - f(2) = 1 - \frac{1}{3} = \frac{2}{3}.$$

Since $8 = 2^3$:

$$g(8) = g(2 \cdot 2 \cdot 2) = g(2)^3 = \left(\frac{2}{3}\right)^3 = \frac{8}{27}.$$

**Converting back:**

$$f(8) = 1 - g(8) = 1 - \frac{8}{27} = \frac{27 - 8}{27} = \frac{19}{27}.$$

Answer: **E**.
</Solution>
