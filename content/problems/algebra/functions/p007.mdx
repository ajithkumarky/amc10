<Problem>
A function $f$ is defined on the integers and satisfies $f(x + 1) - f(x) = 2x + 3$ for every integer $x$. If $f(0) = 1$, what is $f(5)$?
</Problem>

<Solution>
Use the recurrence to telescope from $f(0)$ to $f(5)$.

Summing the recurrence for $x = 0, 1, 2, 3, 4$:

$$\sum_{x=0}^{4} \bigl[f(x+1) - f(x)\bigr] = \sum_{x=0}^{4} (2x + 3).$$

The left side telescopes to $f(5) - f(0)$. The right side is:

$$\sum_{x=0}^{4} (2x + 3) = (3) + (5) + (7) + (9) + (11) = 35.$$

Therefore:

$$f(5) - f(0) = 35 \implies f(5) = 1 + 35 = 36.$$

Answer: **B**.
</Solution>

<AlternateMethod title="Step by step">
Build a table using $f(x+1) = f(x) + 2x + 3$:

| $x$ | $f(x)$ |
|-----|--------|
| 0 | 1 |
| 1 | $1 + 3 = 4$ |
| 2 | $4 + 5 = 9$ |
| 3 | $9 + 7 = 16$ |
| 4 | $16 + 9 = 25$ |
| 5 | $25 + 11 = 36$ |

The outputs $1, 4, 9, 16, 25, 36$ are exactly $(n+1)^2$ for $n = 0, 1, 2, 3, 4, 5$. We can verify: $f(n) = (n+1)^2$ satisfies $f(0) = 1$ and $(n+2)^2 - (n+1)^2 = 2n+3$. ✓
</AlternateMethod>
