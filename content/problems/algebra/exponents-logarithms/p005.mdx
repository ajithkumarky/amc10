<Problem>
If $4^x = 5$, what is $4^{3x}$?
</Problem>

<Solution>
We need $4^{3x}$ in terms of the given information $4^x = 5$.

Rewrite $4^{3x}$ using the power rule:

$$4^{3x} = \left(4^x\right)^3.$$

Substitute $4^x = 5$:

$$4^{3x} = 5^3 = 125.$$

Answer: **E**.
</Solution>
