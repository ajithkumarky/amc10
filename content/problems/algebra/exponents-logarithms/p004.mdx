<Problem>
What is $\log_3 27 + \log_3 \dfrac{1}{9}$?
</Problem>

<Solution>
Evaluate each logarithm by asking "to what power must $3$ be raised to get this number?"

$$\log_3 27 = \log_3 3^3 = 3.$$

$$\log_3 \frac{1}{9} = \log_3 3^{-2} = -2.$$

(Since $\frac{1}{9} = \frac{1}{3^2} = 3^{-2}$, and $\log_b b^r = r$ directly.)

Therefore:

$$\log_3 27 + \log_3 \frac{1}{9} = 3 + (-2) = 1.$$

Answer: **D**.
</Solution>

<AlternateMethod title="Product rule first">
Combine using the log product rule before evaluating:

$$\log_3 27 + \log_3 \frac{1}{9} = \log_3\!\left(27 \cdot \frac{1}{9}\right) = \log_3 3 = 1.$$
</AlternateMethod>
