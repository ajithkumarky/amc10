<Problem>
A sequence is defined by $a_1 = 1$ and $a_{n+1} = \dfrac{a_n}{a_n + 2}$ for all $n \geq 1$. What is $a_{10}$?
</Problem>

<Solution>
Taking reciprocals is the key move. Let $b_n = \dfrac{1}{a_n}$. The recurrence gives:

$$\frac{1}{a_{n+1}} = \frac{a_n + 2}{a_n} = 1 + \frac{2}{a_n},$$

so $b_{n+1} = 2b_n + 1$. The fixed point of $x = 2x + 1$ is $x = -1$, so define $c_n = b_n + 1$. Then:

$$c_{n+1} = b_{n+1} + 1 = (2b_n + 1) + 1 = 2(b_n + 1) = 2c_n.$$

So $\{c_n\}$ is geometric with ratio $2$. Since $b_1 = 1/a_1 = 1$, we have $c_1 = b_1 + 1 = 2$, and thus:

$$c_n = 2 \cdot 2^{n-1} = 2^n.$$

Therefore $b_n = c_n - 1 = 2^n - 1$, and:

$$a_n = \frac{1}{2^n - 1}.$$

At $n = 10$:

$$a_{10} = \frac{1}{2^{10} - 1} = \frac{1}{1023}.$$

*(Quick check: $a_1 = 1/(2-1) = 1$ ✓, $a_2 = 1/(4-1) = 1/3$; verify directly: $a_2 = 1/(1+2) = 1/3$ ✓.)*

Answer: **D**.
</Solution>
