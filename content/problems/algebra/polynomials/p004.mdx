<Problem>
For what value of $k$ is $(x - 2)$ a factor of $p(x) = x^3 + kx^2 - 4x + 4$?
</Problem>

<Solution>
By the Factor Theorem, $(x - 2)$ is a factor of $p(x)$ if and only if $p(2) = 0$.

$$p(2) = 2^3 + k(2^2) - 4(2) + 4 = 8 + 4k - 8 + 4 = 4 + 4k.$$

Setting this equal to zero: $4 + 4k = 0$, so $k = -1$.

Answer: **D**.
</Solution>
