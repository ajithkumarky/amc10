<Problem>
In how many ways can $5$ identical books be distributed among $3$ distinct shelves so that each shelf receives at least $1$ book?
</Problem>

<Solution>
Let $x_1, x_2, x_3$ be the number of books on shelves $1, 2, 3$. We need the number of positive-integer solutions to:
$$x_1 + x_2 + x_3 = 5, \quad x_i \ge 1.$$

**Substitution.** Let $y_i = x_i - 1 \ge 0$. Then $y_1 + y_2 + y_3 = 2$.

The number of non-negative integer solutions to $y_1 + y_2 + y_3 = 2$ is given by stars-and-bars:
$$\binom{2 + 3 - 1}{3 - 1} = \binom{4}{2} = 6.$$

We can verify by listing all solutions $(y_1, y_2, y_3)$: $(2,0,0), (0,2,0), (0,0,2), (1,1,0), (1,0,1), (0,1,1)$ — exactly $6$.

Answer: **D**.
</Solution>
