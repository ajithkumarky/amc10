<Problem>
For how many integers $n$ with $1 \le n \le 100$ is $\gcd(n^2 + n + 1,\; n^2 - 1)$ greater than $1$?
</Problem>

<Solution>
Factor $n^2 - 1 = (n-1)(n+1)$, so we need $\gcd(n^2+n+1, (n-1)(n+1)) > 1$.

**Step 1: Analyze $\gcd(n^2+n+1,\, n+1)$.**

Divide $n^2+n+1$ by $n+1$:
$$n^2 + n + 1 = n(n+1) + 1,$$
so $n^2+n+1 \equiv 1 \pmod{n+1}$. Therefore $\gcd(n^2+n+1, n+1) = 1$ for every $n$.

**Step 2: Analyze $\gcd(n^2+n+1,\, n-1)$.**

Substitute $n \equiv 1 \pmod{n-1}$:
$$n^2 + n + 1 \equiv 1 + 1 + 1 = 3 \pmod{n-1}.$$

So $\gcd(n^2+n+1, n-1)$ divides $\gcd(3, n-1)$, which is either $1$ or $3$.

**Step 3: Combine.**

Since the gcd with $n+1$ is always $1$, we have
$$\gcd(n^2+n+1,\, n^2-1) = \gcd(n^2+n+1,\, n-1) \in \{1, 3\}.$$

The gcd equals $3$ exactly when $3 \mid n-1$, i.e.\ $n \equiv 1 \pmod{3}$.

*Check:* if $n \equiv 1 \pmod 3$, then $n^2+n+1 \equiv 1+1+1 = 3 \equiv 0 \pmod 3$, confirming $3 \mid n^2+n+1$. ✓

**Step 4: Count $n \equiv 1 \pmod{3}$ in $\{1, 2, \ldots, 100\}$.**

These are $n = 1, 4, 7, \ldots, 100$. The count is
$$\frac{100 - 1}{3} + 1 = 33 + 1 = 34.$$

*(Note: $n = 1$ gives $n^2 - 1 = 0$, and $\gcd(3, 0) = 3 > 1$, so $n = 1$ is correctly included.)*

Answer: **C**.
</Solution>
