<Problem>
How many ordered pairs $(a, b)$ of positive integers satisfy $\gcd(a, b) = 6$ and $a + b = 90$?
</Problem>

<Solution>
Since $\gcd(a, b) = 6$, write $a = 6m$ and $b = 6n$ where $m, n$ are positive integers with $\gcd(m, n) = 1$.

Substituting into $a + b = 90$:
$$6m + 6n = 90 \implies m + n = 15.$$

We need to count ordered pairs $(m, n)$ of positive integers with $m + n = 15$ and $\gcd(m, n) = 1$.

The pairs $(m, n)$ with $m + n = 15$ and $1 \le m \le 14$ are:

| $(m, n)$ | $\gcd(m, n)$ | coprime? |
|----------|--------------|---------|
| $(1, 14)$ | $1$ | ✓ |
| $(2, 13)$ | $1$ | ✓ |
| $(3, 12)$ | $3$ | ✗ |
| $(4, 11)$ | $1$ | ✓ |
| $(5, 10)$ | $5$ | ✗ |
| $(6, 9)$ | $3$ | ✗ |
| $(7, 8)$ | $1$ | ✓ |
| $(8, 7)$ | $1$ | ✓ |
| $(9, 6)$ | $3$ | ✗ |
| $(10, 5)$ | $5$ | ✗ |
| $(11, 4)$ | $1$ | ✓ |
| $(12, 3)$ | $3$ | ✗ |
| $(13, 2)$ | $1$ | ✓ |
| $(14, 1)$ | $1$ | ✓ |

The coprime pairs are: $(1,14),(2,13),(4,11),(7,8),(8,7),(11,4),(13,2),(14,1)$ — exactly $8$ ordered pairs.

Answer: **A**.
</Solution>
