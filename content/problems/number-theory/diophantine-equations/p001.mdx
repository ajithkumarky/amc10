<Problem>
How many non-negative integer solutions $(x, y)$ does the equation $2x + 3y = 12$ have?
</Problem>

<Solution>
We need $x \geq 0$, $y \geq 0$, and $2x + 3y = 12$.

Since $3y \leq 12$, we have $y \leq 4$. Check each non-negative value of $y$:

- $y = 0$: $2x = 12 \Rightarrow x = 6$. ✓
- $y = 1$: $2x = 9 \Rightarrow x = 4.5$. Not an integer. ✗
- $y = 2$: $2x = 6 \Rightarrow x = 3$. ✓
- $y = 3$: $2x = 3 \Rightarrow x = 1.5$. Not an integer. ✗
- $y = 4$: $2x = 0 \Rightarrow x = 0$. ✓

The solutions are $(6, 0)$, $(3, 2)$, and $(0, 4)$.

Answer: **C**.
</Solution>
