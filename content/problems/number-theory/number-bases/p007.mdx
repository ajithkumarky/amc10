<Problem>
A 4-digit base-7 number $\overline{abcd}_7$ has all four digits distinct and nonzero, and satisfies $a + c = b + d$. How many such numbers are there?
</Problem>

<Solution>
The digits $a, b, c, d$ are distinct elements of $\{1, 2, 3, 4, 5, 6\}$ with $a + c = b + d$.

**Step 1: Find pairs of disjoint 2-element subsets with equal sums.**

Let $S = a + c = b + d$. We need two disjoint 2-element subsets of $\{1,\ldots,6\}$, each summing to $S$.

List all 2-element subsets by sum:
- $S = 3$: $\{1,2\}$ — only one subset, can't form a disjoint pair.
- $S = 4$: $\{1,3\}$ — only one, can't form a disjoint pair.
- $S = 5$: $\{1,4\}, \{2,3\}$ — 1 disjoint pairing.
- $S = 6$: $\{1,5\}, \{2,4\}$ — 1 disjoint pairing.
- $S = 7$: $\{1,6\}, \{2,5\}, \{3,4\}$ — $\binom{3}{2} = 3$ disjoint pairings.
- $S = 8$: $\{2,6\}, \{3,5\}$ — 1 disjoint pairing.
- $S = 9$: $\{3,6\}, \{4,5\}$ — 1 disjoint pairing.
- $S = 10$: $\{4,6\}$ — only one, can't form a disjoint pair.
- $S = 11$: $\{5,6\}$ — only one, can't form a disjoint pair.

Total unordered pairings: $1 + 1 + 3 + 1 + 1 = 7$.

**Step 2: Count ordered 4-tuples $(a, b, c, d)$ per pairing.**

For each pairing $(\{x_1, x_2\}, \{y_1, y_2\})$ (the first set will fill positions $a, c$ and the second fills $b, d$):
- Assign $\{x_1, x_2\}$ to positions $(a, c)$: 2 ways.
- Assign $\{y_1, y_2\}$ to positions $(b, d)$: 2 ways.
- The two sets can also be swapped (first set goes to $b,d$, second to $a,c$): multiply by 2.

Each unordered pairing yields $2 \times 2 \times 2 = 8$ valid 4-tuples.

**Step 3: Total count.**

$$7 \times 8 = \mathbf{56}.$$

Answer: **D**.
</Solution>

<AlternateMethod title="Verification for S = 7">
For $S = 7$ with pairing $\{1,6\}$ and $\{2,5\}$, the 8 numbers are:
$\overline{1256}_7$, $\overline{1652}_7$, $\overline{6125}_7$, $\overline{6521}_7$ (with $\{a,c\}=\{1,6\}$, $\{b,d\}=\{2,5\}$) and $\overline{2165}_7$, $\overline{2561}_7$, $\overline{5162}_7$, $\overline{5621}_7$ (swapped sets). Each satisfies $a + c = b + d = 7$. ✓
</AlternateMethod>
