<Problem>
What is the distance from the point $(2, 5)$ to the line $3x - 4y + 1 = 0$?
</Problem>

<Solution>
The distance from point $(x_0, y_0)$ to the line $ax + by + c = 0$ is

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}.$$

Here $a = 3$, $b = -4$, $c = 1$, and $(x_0, y_0) = (2, 5)$.

**Numerator:**

$$|3(2) + (-4)(5) + 1| = |6 - 20 + 1| = |-13| = 13.$$

**Denominator:**

$$\sqrt{3^2 + (-4)^2} = \sqrt{9 + 16} = \sqrt{25} = 5.$$

**Distance:**

$$d = \frac{13}{5}.$$

Answer: **A**.
</Solution>
