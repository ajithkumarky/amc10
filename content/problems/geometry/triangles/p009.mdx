<Problem>
A right triangle has a perimeter of $60$ and an area of $150$. What is the length of its hypotenuse?
</Problem>

<Solution>
Let the two legs be $a$ and $b$, and the hypotenuse be $c$.

**Set up the system:**
$$a + b + c = 60 \implies a + b = 60 - c \tag{1}$$
$$\tfrac{1}{2}ab = 150 \implies ab = 300 \tag{2}$$
$$a^2 + b^2 = c^2 \tag{3}$$

**Eliminate $a$ and $b$.** Use the identity $a^2 + b^2 = (a+b)^2 - 2ab$:

$$(a+b)^2 - 2ab = c^2$$
$$(60 - c)^2 - 2(300) = c^2$$
$$3600 - 120c + c^2 - 600 = c^2$$
$$3000 = 120c$$
$$c = 25$$

**Verify.** From (1): $a + b = 35$. From (2): $ab = 300$. So $a$ and $b$ satisfy $t^2 - 35t + 300 = 0$, giving $t = \dfrac{35 \pm \sqrt{1225 - 1200}}{2} = \dfrac{35 \pm 5}{2}$, so $t = 20$ or $t = 15$.

Check: $15^2 + 20^2 = 225 + 400 = 625 = 25^2$. ✓ This is a $15$-$20$-$25$ triangle (a scaled $3$-$4$-$5$).

Answer: **D**.
</Solution>
